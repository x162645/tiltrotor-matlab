# NACA TN 626 简单旋翼验模资料契约

## 目的和边界

本算例只检验当前旋翼叶素—动量方程在简单孤立旋翼悬停条件下，能否同时给出合理的推力系数和功率系数。它不修改生产模型，不反向拟合试验结果，也不代表倾转旋翼机整机验模。

原始资料为 Knight 与 Hefner 的 NACA TN 626《Static Thrust Analysis of the Lifting Airscrew》，美国国家航空航天局记录号 19930081433：

- 资料页：https://ntrs.nasa.gov/citations/19930081433
- 原始文件：https://ntrs.nasa.gov/api/citations/19930081433/downloads/19930081433.pdf
- 本次核对文件的 SHA-256：`420F19CD396C36D45CFF1646C7FC09300527B8E0CF728896AF5632DA9A47F7D6`

原文表 III 的推力、扭矩系数采用两倍于当前通用定义的归一化。因此比较时固定换算为：

```text
当前标准推力系数 = 原文推力系数 / 2
当前标准功率系数 = 原文扭矩系数 / 2
```

试验数值保存在 `NACA_TN_626_TABLE_III_FOUR_BLADE.csv`。表 III 位于原文第35页、PDF 第37页。

## 预先声明的检验规则

- 只计算桨距 2°、3°、4°、5°、6°、7°、8°，每点一次。
- 0°和1°不进入主检验，因为当前诱导速度求解器只正式支持正推力分支，而且接近零的相对误差没有稳定解释。
- 9°至12°不进入主检验，因为同一报告指出高桨距时翼型升力已明显偏离线性关系；本轮先检验简单工作段。
- 预测完成以后才读取表 III 的目标值。
- 不更改模型方程，不扫网格，不扫参数，不运行备选翼型参数。
- 7 个点必须全部满足代码现有的物理收敛判据。
- 推力系数平均绝对百分比误差不超过 15%。
- 功率系数平均绝对百分比误差不超过 20%。
- 上述误差线只是本项目判别“简单旋翼低阶验模是否通过”的预先筛查线，不是通用适航或行业标准。

## 已知但不补模的差异

- 当前模型用等弦长和一个气动积分起点，忽略5英寸半径以内的小根部过渡段。
- 试验桨距以逐片零推力角为零点；代码将其近似映射为对称翼型的零升力角，二者并非严格同一物理定义。
- 当前升力曲线用平滑饱和函数表示，原报告在主检验区间主要采用线性升力关系。
- 当前模型没有雷诺数变化、三维根尖损失、尾流收缩和试验装置细节。
- 报告没有桨叶质量与惯量。代码保留概念桨叶质量，并按新半径重算惯量；在本次轴对称、竖轴归一化的悬停计算中，它只影响锥度求解，不进入推力和扭矩积分。
- 实验转轴水平；本算例采用竖轴归一化以排除没有资料支持的重力周期挥舞。由此得到的是气动核心比较，不是试验装置完整复现。
- 诱导速度初值仍由概念整机质量产生；该质量只用于当前求解器的初值，不进入最终推力、功率系数。若计算不收敛，应先判为数值初值问题，不能直接判为物理模型错误。

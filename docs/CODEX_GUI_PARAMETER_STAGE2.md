# GUI 参数目录阶段说明

本文档保留为历史入口，当前要求已由综合 GUI 审查与重构任务取代。

## 当前实现要点

- 参数目录由 `services/build_parameter_catalog.m` 生成。
- 参数只按物理部件和计算模块分类。
- GUI 不设置用户能力分层。
- 参数页支持类别筛选、关键词筛选和修改状态筛选。
- 编辑采用“暂存修改，然后应用”的流程。
- 应用成功后清空依赖的配平、线性化和响应结果。
- 参数保存和加载使用带 `formatVersion` 的 MAT 项目文件。

## 仍需遵守

- 不修改物理参数数值作为通过测试的手段。
- 不修改模型方程、配平算法、线性化算法或响应算法。
- MATLAB R2021a 兼容性优先。
- 聚焦测试先行，再决定是否运行完整检查。

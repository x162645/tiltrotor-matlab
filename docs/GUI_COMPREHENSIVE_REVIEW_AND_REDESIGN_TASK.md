## 3. 核心设计原则

### 3.1 GUI 面向专业使用者，但必须直接、清楚

本软件的使用者本身具备工程或研究背景，不需要设置“普通、常用、高级、专家”等用户层级。

专业软件仍应避免把代码字段名、内部矩阵结构、求解器内部术语和含糊工程词直接当作主界面语言。

界面名称必须优先回答：

1. 这是什么；
2. 单位是什么；
3. 正方向或定义是什么；
4. 修改后影响什么；
5. 它能否直接编辑。

### 3.2 正常功能分类，不做用户层级分类

彻底删除以下概念：

- 常用；
- 高级；
- 专家；
- 全部层级；
- 参数层级；
- 任何基于上述层级的筛选、字段、测试和文档。

参数只按物理部件或计算模块分类。

### 3.3 专业符号可以保留，代码变量名不能单独显示

推荐格式：

```text
纵向速度 u
俯仰角 θ
滚转惯量 Ixx
总距 collective 不应单独显示，应显示“总距”
```

代码变量可作为次要信息、提示信息或技术详情显示，但不能代替中文名称。

### 3.4 主界面结论与技术细节分开

主界面直接显示：

- 成功或失败；
- 关键原因；
- 下一步建议；
- 当前结果是否有效。

以下内容放在可展开的“技术信息”中：

- 原因代码；
- MATLAB 错误标识；
- 调用栈；
- 求解器退出标志；
- 原始异常内容。

### 6.1 删除含糊词和代码式名称

以下现有或同类名称必须重写：

| 不合适名称 | 推荐名称 |

| 名义惯量矩阵 Ixz | 滚转—偏航耦合惯量 Ixz |
| 名义惯量矩阵 Iyz | 俯仰—偏航耦合惯量 Iyz |

### 6.2 气动导数改成“谁对谁的影响”

例如：

| 当前名称 | 推荐名称 |
|---|---|
| 机翼侧力侧滑导数 | 侧滑对机翼侧向力的影响（CYβ） |

| 副翼俯仰力矩导数 | 副翼对俯仰力矩的影响 |
| 方向舵侧力导数 | 方向舵对侧向力的影响 |

### 6.3 参数详情必须包含

每个参数的详情区域至少显示：

- 含义；
- 物理或数值影响；
- 当前单位；
- 允许范围；
- 数据来源；
- 是否可以直接编辑；
- 关联参数或自动更新关系。

“依据：环境设定”“依据：质量与惯量设定”这类空泛文字不得继续使用。

数据来源显示可映射为：

- 文献数据；
- 图表数字化；
- 公式推导；
- 当前模型设定；
- 临时占位；
- 来源待确认；
- 数值计算设置；
- 自动计算。

底层来源枚举仍遵守 `AGENTS.md`，界面显示使用自然中文。

## 7. 参数页重构要求

### 7.1 页面名称

将 `关键参数` 改为：

```text
参数设置
```

139 项完整参数不能称为“关键参数”。

### 7.2 删除层级相关控件

删除：

- 层级下拉框；
- 常用、高级、全部层级选项；
- 表格层级列；
- 参数目录中的层级字段；
- 层级筛选服务；
- 层级相关测试。

### 7.3 参数表推荐列

```text
类别 | 参数 | 默认值 | 当前值 | 单位 | 状态 | 来源
```

要求：

- 当前值可编辑；
- 默认值始终可见；
- 修改后当前值高亮；
- 状态显示“未修改、已修改、自动计算、输入有误”；
- 自动计算项只读；
- 代码字段名不作为主要列；
- 代码字段可在详情或技术信息中显示。

### 7.4 编辑流程

当前每修改一个单元格就对整组参数执行完整校验的方式会阻碍成组修改。

改为：

1. 单元格编辑时检查数据类型和该参数自身基本范围；
2. 修改进入“待应用”状态；
3. 用户点击 `应用修改` 后执行整组参数校验；
4. 整组校验失败时保留用户输入；
5. 清楚标出关联错误，不直接把所有输入回滚；
6. 应用成功后清空已有配平、线性化和响应结果；
7. 提供逐项恢复和全部恢复。

### 7.5 按钮名称

不使用含义不清的“撤销修改”。

推荐：

- 应用修改；
- 恢复选中参数；
- 恢复全部参数；
- 参数检查。

只有真正实现编辑历史栈时，才允许使用“撤销上一步”。

### 7.6 自动计算项

自动计算参数必须只读并明确标记，例如：

- 桨盘面积；
- 旋翼实度；
- 由几何和质量推导的惯量或重心结果；
- 由基础参数更新的桨叶惯量。

基础参数和派生参数不得同时无约束编辑。

### 7.7 单位显示

删除“显示单位 / 内部单位”重复展示。

规则：

- 表格只显示用户输入和查看所用单位；
- 角度参数直接显示 `°`；
- 内部 rad 转换仅在技术说明中出现；
- 同一参数的单位不得在多个位置重复造成噪声。

## 8. 顶部状态和工作流状态

一个状态灯不足以表达整条计算链。

顶部推荐显示：

```text
参数：已检查 | 配平：未运行 | 线性化：未运行 | 响应：未运行
```

参数变化后：

```text
参数：已修改 | 配平：需重新计算 | 线性化：无效 | 响应：无效
```

结果状态必须准确反映依赖关系：

- 参数变化使所有后续结果失效；
- 新配平使旧线性化和响应失效；
- 新线性化使旧响应失效。

## 10. 配平页面重构

### 10.1 输入区域拆分

拆成两个功能区：

#### 飞行工况

- 空速；
- 短舱倾转角；
- 航迹角。

#### 配平计算

- 初始俯仰角；
- 初始总距；
- 初始纵向周期变距；
- 俯仰搜索范围；
- 多初值设置。

### 10.2 输入定义必须直接显示

关键输入旁必须显示或可立即查看：

- 空速的定义；
- 短舱倾转角的零点和方向；
- 航迹角正方向；
- 初值只影响求解起点，不是最终结果。

短舱角示例文字必须依据代码真实定义，不得猜测：

```text
短舱倾转角 βM（0°：……，90°：……）
```

### 10.3 多初值文字

将：

```text
总是完成全部初值
```

改为：

```text
找到可用解后继续计算其余初值
```

并提示会增加计算时间。

### 10.4 运行进度和取消

配平可能执行多初值和内部迭代，增加：

- 当前候选编号；
- 已完成数量；
- 运行时间；
- 停止计算按钮。

不得仅依赖等待鼠标指针。

### 10.5 配平结果页

保留但重新整理为：

1. 结果总览；
2. 状态与操纵；
3. 力和力矩平衡；
4. 残差与限幅；
5. 多初值结果。

总览必须直接显示：

- 配平是否可接受；
- 最终俯仰角；
- 最终操纵量；
- 残差是否满足要求；
- 是否触及限幅；
- 是否可以继续线性化。

### 10.6 力和力矩平衡

至少显示：

- 总推力和重量；
- 纵向、侧向、垂向合力；
- 滚转、俯仰、偏航合力矩；
- 主要部件的载荷贡献；
- 哪些状态导数属于配平目标。

### 10.7 多初值候选表

主表不再一次显示过多内部字段。

推荐列：

```text
候选 | 初始值组合 | 最终配平值 | 残差 | 操纵范围 | 结果
```

选中候选后再显示：

- 目标函数；
- 退出标志；
- 完整初始值；
- 完整最终值；
- 限幅裕度；
- 原因代码。

## 12. 线性化与模态页面重构

### 12.1 线性化点信息

页面顶部优先显示：

- 空速；
- 短舱倾转角；
- 航迹角；
- 配平状态；
- 线性化时间；
- 当前结果是否仍有效。

删除长期占位文字：

```text
A: 9×9，B: 9×7；中心差分步长来自当前参数
```

矩阵尺寸和差分方法放进结果说明或技术信息。

### 12.2 A、B 矩阵

必须明确：

- 行状态导数名称和单位；
- 列状态或操纵量名称和单位；
- 操纵输入在线性化中使用 rad 还是 deg；
- 单击单元格时显示该偏导数的物理含义和单位。

### 12.3 模态分类

不能只按右半平面判断稳定或不稳定。至少区分：

- 稳定；
- 弱阻尼；
- 接近临界稳定；
- 接近零特征值；
- 不稳定；
- 数值结果需复核。

判据沿用现有模型和容限逻辑，界面不要夸大结论。

### 12.4 独立导出

提供：

- 复制 A 矩阵；
- 复制 B 矩阵；
- 导出 CSV；
- 导出 MAT；
- 导出特征值表；
- 保存特征值图。

## 14. 保存、加载和会话管理

### 14.1 改名

当前“导出工况”实际包含参数、配平、线性化和响应结果，应改为：

```text
保存项目
```

或：

```text
保存分析结果
```

### 14.2 增加加载

增加：

- 加载项目；
- 恢复保存时的参数；
- 恢复已有配平、线性化和响应结果；

- 是否有未应用或未保存参数修改；

### 14.4 文件格式

保留版本字段，例如：

```text

```

## 17. 数值计算参数的显示原则

- 配平计算；
- 线性化计算；

- 响应计算。

- 最大迭代次数；
- 收敛精度；

- 操纵量差分步长；
- 诱导速度松弛系数；
- 挥舞方程差分步长。

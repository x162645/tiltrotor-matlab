## 3. 受载扭转方向

来源约束的结构包给出的受载变形方向是**负扭转，即局部几何桨距减小**。

全参考柔性配置在 6°–11°范围内：

- 控制系统整体桨距柔度约 `-0.157°` 至 `-0.204°`；
- 0.75R 总受载扭转约 `-0.676°` 至 `-0.939°`；
- 桨尖附近总受载扭转约 `-1.296°` 至 `-1.947°`；
- 单独桨叶结构扭转在桨尖约 `-1.045°` 至 `-1.585°`。

随着总距和载荷增加，负扭转幅值总体增大。

因此，在当前 NASA 参考结构包下，旋转受载变形不会把 OARF 报告总距“补大”，反而会降低有效桨距。

## 4. 气动力矩分解

刚性 M1-B 工况中的单片平均气动扭矩约为 `-83` 至 `-118 N·m`。

其组成具有稳定结构：

- C81 四分之一弦俯仰力矩贡献约 `-165` 至 `-172 N·m`，为主要低头力矩；
- XQC 偏置载荷贡献约 `+54` 至 `+82 N·m`，部分抵消 C81 低头力矩；
- 两者合成后仍为负，因此产生减小桨距的受载扭转。

在柔性反馈后，力矩数值有所变化，但总扭矩仍保持负值。

## 5. 科学结论

第二阶段提供了一个明确的排除性结果：

> 在 NASA/TP-2004-212262 公开 XV-15 CAMRAD II 参考结构输入和 C81 俯仰力矩数据约束下，准静态受载弹性扭转不仅不能解释当前 M1-B 的 CT/CP 系统性低估，反而会进一步降低有效桨距并扩大 CT/CP 误差。

因此，不应再通过“假设旋转后实际桨距比报告值大数度”来解释当前误差，除非未来获得与 OARF 生产钢桨和控制链直接对应、且与当前参考结构包相矛盾的更高等级实测证据。

这个结论的边界同样重要：公开参考 CAMRAD II 模型基于较早的预生产桨叶数据，控制系统 spider 运动学也有已知简化，因此本结果只能排除**当前公开参考结构包下的准静态扭转**为主要误差来源，不能宣称已经排除生产 XV-15 的全部气弹性效应。

## 6. 对 M1 路线的影响

M1 当前误差来源优先级应重新排序：

1. 截面气动与径向几何：已证实有显著贡献；
2. 简单径向环带入流：贡献有限；
3. 公开参考结构包下的准静态受载扭转：方向相反，不能解释剩余低估；
4. 下一主线：**非局部有限叶片尾迹与诱导耦合**；
5. 次级待审计：C81/几何参考模型与实际 OARF 钢桨之间的来源差异、雷诺数/粗糙度/转捩，以及 CP 的旋转组件边界。

因此下一阶段不再继续增加经验桨距偏置或调整结构刚度，而进入规定螺旋尾迹/升力线/Biot-Savart 的非局部尾迹研究。

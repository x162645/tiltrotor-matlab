# XV-15 截面气动低阶化与悬停验模更新

## 1. 这一步到底在做什么

本项目研究对象仍然是**通用低阶倾转旋翼模型**。本轮不把模型改成 XV-15 专用模型，而是为当前通用参数字段

\[
\alpha_{0L},\quad a,\quad C_{L\max},\quad C_{D0},\quad k_D
\]

确定一套可用于 XV-15 验模的低阶等效取值。

核心逻辑是：

\[
\text{XV-15 公开参考截面气动}
\rightarrow
\text{当前低阶参数形式}
\rightarrow
\text{不改低阶旋翼方程}
\rightarrow
\text{与 OARF 真实悬停试验比较}.
\]

这样可以先排除“参数仍是通用默认值”造成的误差，再把剩余误差用于判断低阶模型形式的局限。

## 2. 为什么撤销上一版的 design-Cl -> alpha0L 推导

上一版根据 NACA 6 系列编号中的设计升力系数使用

\[
\alpha_{0L}\approx-C_{l,design}/a
\]

构造了约 \(-1.70^\circ\) 的等效零升力角。重新审查后确认，NACA 6 系列的设计升力系数不是 \(C_L(\alpha=0)\)，因此该关系只能作为探索性敏感性估算，不能作为严格的 XV-15 参数来源。

本版不再使用该数值，也不再把上一版 43.86% / 51.90% 的改善结果解释为独立参数驱动的定量归因。

## 3. 更合适的独立参数源：NASA XV-15 C81 表

NASA/TP-2004-212262 Appendix A 公开了其 XV-15 CAMRAD II 基线模型所用的二维旋翼截面气动输入，标题明确为：

`XV-15 ROTOR AIRFOILS (64X28/18/12/08) (C81 TABLES; INTERPOLATED SPANWISE)`。

报告同时说明其 baseline rotor 是原始 XV-15 steel-blade rotor。公开 C81 表按径向区段给出随迎角和马赫数变化的二维升力、阻力和力矩数据。

证据等级必须明确：

- C81 表是 **NASA XV-15 参考分析模型的公开气动输入**；
- 它们不是 OARF Run 15 悬停试验数据；
- 也不应称为各翼型的原始风洞测量真值；
- 因而本轮属于“参考模型输入 -> 当前低阶参数”的独立约化，OARF 数据仍可作为外部试验比较对象。

这比从翼型编号间接猜一个零升力角更直接，也与当前程序真正需要的参数形式更匹配。

## 4. C81 到当前低阶参数的约化

当前模型截面气动力形式为

\[
C_L=C_{L\max}\tanh\left[\frac{a(\alpha-\alpha_{0L})}{C_{L\max}}\right],
\]

\[
C_D=C_{D0}+k_D C_L^2.
\]

因此无需把完整 C81 表塞入 production 模型，而是直接把 C81 表约化到这五个通用参数字段。

### 4.1 径向/Mach 处理

采用 OARF 悬停组的代表桨尖速度 768 ft/s。四个 NASA C81 区段按报告边界取：

- 0.20--0.55R
- 0.55--0.80R
- 0.80--0.95R
- 0.95--1.00R

升力对悬停推力的一阶贡献近似随 \(c r^2\) 加权，因此用 \(c r^2\) 得到各段代表半径和权重；阻力矩额外含一个力臂，因此阻力参数约化使用 \(c r^3\) 权重。

这只是为了把真实径向变化压缩成当前标量参数，不改变模型形式。

### 4.2 升力参数

在每个区段代表 Mach 上对 C81 数据作线性 Mach 插值，然后在 \(-6^\circ\le\alpha\le12^\circ\) 内直接最小化当前低阶升力形式与 C81 数据之间的径向加权残差，同时识别：

\[
a,\quad \alpha_{0L},\quad C_{L\max}.
\]

方程级复现得到约：

\[
\boxed{a_{eq}=7.81\;\mathrm{rad^{-1}}}
\]

\[
\boxed{\alpha_{0L,eq}=-1.034^\circ}
\]

\[
\boxed{C_{L\max,eq}=1.279}
\]

这些是 **NASA C81 参考表到本项目低阶形式的拟合值**，不是 NASA 文献直接报告的三个 XV-15 标量。

### 4.3 阻力参数

使用 C81 在代表 Mach 下的 \(-4^\circ\le\alpha\le8^\circ\) 数据，并以 \(c r^3\) 权重拟合当前二次阻力形式：

\[
C_D=C_{D0}+k_D C_L^2.
\]

方程级复现得到约：

\[
\boxed{C_{D0,eq}=0.00497}
\]

\[
\boxed{k_{D,eq}=0.02486}
\]

该范围避免把深失速数据强行压缩进一个二次阻力式，同时保留悬停外段在较高 Mach 下已经出现的阻力上升。

## 5. 为什么本版不再叠加单独的 PG 修正

上一版还额外使用了 0.75R 的 Prandtl-Glauert 型升力斜率修正。

本版 C81 数据本身已经以 Mach 为维度，并在各径向段按悬停代表 Mach 进行了插值。因此再在约化后的 \(a\) 上叠加 PG 修正会重复计入压缩性影响。本版关闭该额外修正。

## 6. 方程级复现的外部比较结果

仍采用与 PR #67 相同的共同物理收敛区间：\(\theta_{75}=6^\circ\) 到 \(11^\circ\)。OARF CT/CP/FM 没有进入任何 C81 参数识别过程。

| 参数方案 | CT MAPE | CP MAPE | FM MAPE |
|---|---:|---:|---:|
| PR #67 通用默认截面参数 | 56.42% | 62.61% | 23.02% |
| NASA C81 -> 当前低阶参数 | **42.87%** | **51.12%** | **12.22%** |

10° 点：

| | 试验 | PR #67 基线 | C81 低阶参数 |
|---|---:|---:|---:|
| CT | 0.013089 | 0.006396 | **0.008220** |
| CP | 0.001358 | 0.000525 | **0.000700** |
| FM | 0.7797 | 0.6889 | **0.7530** |

因此可以支持两个结论：

1. **通用默认截面气动参数确实是初始 XV-15 悬停误差的重要来源之一。** 把它们替换为与 XV-15 公开参考 C81 数据相匹配的低阶等效参数后，CT、CP 和 FM 均系统改善。
2. **截面参数取值不是全部误差。** 即使这一层已经从 generic 默认值提升为 XV-15 参考等效值，CT 和 CP 仍分别有约 43% 和 51% 的平均相对误差。因此不能把剩余问题继续归咎于“没有使用 XV-15 截面参数”。

这正是逐层误差归因需要的结果。

## 7. 当前可以怎样描述误差来源

截至本版，证据链为：

### 已检查：数值离散

PR #67 的径向/方位离散敏感性远小于外部误差，因此不是主因。

### 已检查：弦长/扭转几何降阶

直接使用真实径向几何的诊断只能小幅提高 CT，无法解释约 50% 的差距，因此不是当前主因。

### 本版检查：截面气动参数仍为 generic 默认值

使用独立 NASA C81 参考表约化后，误差显著下降，因此该层确实有贡献；但仍有很大剩余误差。

### 下一层应检查

在不再调整 C81 标量参数去追 OARF 曲线的前提下，下一步应优先检查当前低阶 **旋翼气动模型形式**：

- 完整径向/Mach 截面变化压缩成单组标量的损失；
- 当前诱导速度/入流分布形式；
- 叶尖损失及有限叶片效应；
- 旋转三维效应；
- 挥舞与载荷耦合的低阶化。

这里已经开始从“参数有没有取对”转入“低阶模型形式是否足够”的问题。

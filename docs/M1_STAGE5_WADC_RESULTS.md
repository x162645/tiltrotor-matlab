# M1 Stage 5：WADC 跨设施 post-freeze 外部验证结果

## 1. 本阶段在项目主线中的位置

本项目的主线不是把低阶模型调成 XV-15 数字孪生，而是研究：一个通用低阶倾转旋翼模型在公开外部证据下能够可信到什么程度；哪些来源受约束的物理增强具有可泛化的改善；剩余误差如何形成可信适用域边界。

因此 Stage 5 的关键不是得到更小的某个单点误差，而是验证以下命题：

> 在 WADC 数值被读取之前已经冻结的 `M1_HOLDOUT_V1`，相对冻结 M0 的改善能否在不同试验设施、不同试验系列和较低尖端马赫数下继续保持。

首次 M1 holdout 冻结记录提交：

`d313296a35319dc8a5e6c398adbed0d54e0f8ede`

冻结模型：

`M1_HOLDOUT_V1 = M1_E1_GENERIC_CORRIGAN_N1`

WADC 数据随后才被录入并执行。因此本阶段分类为：

`POST_FREEZE_CROSS_FACILITY_EXTERNAL_VALIDATION`

它不是 blind validation：分析者在执行阶段能够看到数据，但模型身份、参数选择规则和固定报告窗口已经事先冻结，且禁止根据 WADC 输出修改模型。

## 2. 数据与报告窗口

数据源：NASA/CR-2017-219486 Appendix A Table A-3，XV-15 original metal blade WADC formal Runs 1-3。

三组运行的典型尖端马赫数约为：

- Run 1：`Mtip ≈ 0.53`；
- Run 2：`Mtip ≈ 0.62`；
- Run 3：`Mtip ≈ 0.66`。

报告窗口直接继承冻结前 M0/M1 已使用的 `6 deg <= theta_0.75R <= 11 deg`，不根据 WADC 误差重新选择。

WADC 每个正式 Run 在该窗口中实际存在的点为：

`6, 8, 9, 10, 11 deg`

因此不插值缺失的 7 deg 点。每 Run 5 点，三组共 15 点。全部正式 Run 1-3 源数据保留在 `analysis/data/xv15_wadc_metal_table_a3.csv` 中，窗口外数据未删除。

## 5. M0 跨设施结果

| 验证组 | CT MAPE | CP MAPE | FM MAPE |
|---|---:|---:|---:|
| WADC Run 1 | 58.1453% | 64.6951% | 23.3277% |
| WADC Run 2 | 59.4524% | 66.4597% | 23.1487% |
| WADC Run 3 | 59.8418% | 67.1374% | 22.6727% |
| 三组 pooled | **59.1465%** | **66.0974%** | **23.0497%** |

CT、CP 和 FM pooled 平均有符号误差均为负，说明 M0 在 WADC 上仍保持与 OARF 相似的系统性低估结构。

这一结果进一步支持原 M0 结论：M0 能保持随总距增加的基本载荷趋势，但不能作为 XV-15 原始金属桨悬停 CT/CP 的定量预测模型。

## 6. 冻结 M1 的跨设施结果

| 验证组 | CT MAPE | CP MAPE | FM MAPE |
|---|---:|---:|---:|
| WADC Run 1 | 36.9312% | 49.7163% | 8.5581% |
| WADC Run 2 | 38.2361% | 51.4696% | 9.3807% |
| WADC Run 3 | 38.5196% | 52.1374% | 9.8288% |
| 三组 pooled | **37.8956%** | **51.1078%** | **9.2559%** |

pooled 平均有符号误差：

- CT：`-37.8956%`；
- CP：`-51.1078%`；
- FM：`-0.2731%`。

FM 的 pooled 平均有符号误差接近零不能解释为所有点都准确。FM MAPE 仍为 9.26%，且逐点误差随总距发生由负到正的变化，平均值接近零包含误差抵消。

## 7. M1 相对 M0 的跨设施改善

| 验证组 | CT MAPE 改变量 | CP MAPE 改变量 | FM MAPE 改变量 |
|---|---:|---:|---:|
| Run 1 | -21.2141 pp | -14.9788 pp | -14.7696 pp |
| Run 2 | -21.2164 pp | -14.9901 pp | -13.7679 pp |
| Run 3 | -21.3222 pp | -15.0000 pp | -12.8438 pp |
| pooled | **-21.2509 pp** | **-14.9896 pp** | **-13.7938 pp** |

这里最重要的证据不是单个 pooled 数值，而是三个不同尖端马赫数 Run 的改善量高度一致：

- CT 改善始终约 21.2 pp；
- CP 改善始终约 15.0 pp；
- FM 改善始终约 12.8-14.8 pp。

因此，来源受约束的真实径向几何、完整 C81 与通用旋转失速延迟所形成的 M1 改善，没有只局限在 OARF Run 15 或某一个尖端速度上。

这属于跨设施泛化证据，而不是 WADC 后拟合结果。

## 8. 与 OARF 开发性相关结果的关系

冻结前 OARF Run 15 的 M1-E-1 6-11 deg 结果为：

- CT MAPE：32.7287%；
- CP MAPE：45.8916%；
- FM MAPE：7.5923%。

WADC pooled M1 相比 OARF 的绝对误差略大：

- CT 约增加 5.17 pp；
- CP 约增加 5.22 pp；
- FM 约增加 1.66 pp。

这表明模型并没有因为物理增强而得到“跨设施都很小的误差”。然而，M1 相对 M0 的显著改善在三个 WADC Run 上稳定保留，且残差随总距变化的总体形态与 OARF 一致。

因此更准确的结论是：

> M1 显著降低了可跨设施复现的模型形式偏差，但尚未消除决定 XV-15 悬停绝对载荷水平的主要剩余误差。

## 9. 残差形态与可信域

WADC 三个 Run 上，M1 的 CT/CP 都仍然系统偏低。

典型形态为：

- 6 deg：CT 约低 51%-54%，CP 约低 57%-61%；
- 随总距增加，绝对相对误差逐渐减小；
- 11 deg：CT 约低 27%，CP 约低 44%-45%；
- FM 在低总距偏低，在较高总距逐渐转为偏高。

这与 OARF 上已经看到的“低载荷误差最大、随总距增大逐渐接近”的结构一致。

因此当前可信适用域不能仅用一个 pooled MAPE 描述，而应按预测目标分层。

| 预测对象 / 区域 | 当前证据等级 | 可允许声明 |
|---|---|---|
| 6-11 deg、Mtip 约 0.53-0.69 内 CT/CP 随总距的趋势 | **支持** | 可用于定性趋势与模型间相对比较 |
| M1 相对 M0 的改善方向 | **跨设施支持** | 来源约束物理增强可稳定降低 CT/CP/FM 模型误差 |
| CT 绝对定量预测 | **不支持高精度声明** | OARF 约 33% MAPE，WADC 约 38% MAPE |
| CP 绝对定量预测 | **不支持高精度声明** | OARF 约 46%，WADC 约 51% MAPE |
| FM | **中等诊断可信度** | OARF 约 7.6%，WADC 约 9.3%，但存在逐点正负误差抵消 |
| collective < 6 deg | **低可信 / 当前不支持** | M0 曾有物理分支/求解限制；M1-F 低载荷尾迹出现病态解 |
| collective > 11 deg | **未声明** | 尽管 WADC 有更高总距数据，本研究未在冻结前将其纳入验证窗口 |
| Mtip < 0.53 或 > 0.69 | **未外部验证** | 不外推当前结论 |
| 非局部尾迹 M1-F | **模型形式诊断** | 证明非局部诱导有数个百分点影响，不作为当前主模型 |
| 前飞/完整飞行动力学 | **本阶段不覆盖** | 必须通过独立动态试验同源性门槛后另行验证 |

## 10. WADC 设施限制

WADC Rig #3 并非无干扰“真值”环境。NASA 汇编对工作平台可能引起的干扰地面效应、安全围栏和设施干扰问题保留了明确警告。

本研究没有对 WADC 数据做任何设施修正。

因此 WADC 与 OARF 之间约 5 pp 的绝对误差差异不能简单归因于模型，也不能简单归因于设施。能够较稳妥得出的结论是：M0 的大幅系统性低估以及 M1 相对 M0 的明显改善，在两套设施证据中同时存在。

## 11. Stage 5 的主线结论

Stage 5 不支持“模型已经准确复现 XV-15”。

它支持更有研究价值的结论：

1. M0 的主要 CT/CP 定量偏差跨 OARF 与 WADC 保持，因此不是某一个 Run 的偶然结果；
2. M1 在冻结后、未使用 WADC 调参的情况下，在三个 WADC 尖端马赫数系列中稳定降低 CT、CP 和 FM 误差；
3. 这种改善说明真实径向几何、完整截面气动和来源约束旋转效应具有可泛化价值；
4. M1 仍存在约 38% CT 和 51% CP pooled MAPE，不能称为 XV-15 定量性能模型；
5. 剩余误差应作为低阶模型形式和输入契约的可信域边界，而不是继续使用 WADC 反调当前冻结模型；
6. M1-F 已证明非局部尾迹有次一级影响，但当前规定尾迹内段推广不足以成为完整主模型，因此若未来继续提高旋翼性能精度，应建立新的 M2 身份和新的开发/验证分割。

这使本项目从“开发性相关”进入了真正可写入论文方法学主线的“冻结模型—跨设施外部验证—可信适用域”阶段。

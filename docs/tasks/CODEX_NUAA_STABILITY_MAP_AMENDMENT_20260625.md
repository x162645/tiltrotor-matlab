# Amendment — 全配平网格稳定性分布验证

本文件补充并覆盖 `CODEX_NUAA_TRIM_TREND_VALIDATION_TASK_20260625.md` 中原 Stage 5 的“仅代表点线性化”安排。其余工作区清理、配平策略、参数和输出要求保持不变。

## 为什么需要覆盖

用户指出当前软件可能并非少数工况出现不稳定，而是在较大范围内被标记为开环不稳定。必须验证“不稳定覆盖范围、模态类型和增长率”，不能用少量代表点代替。

当前 `stability_report` 的布尔标志只要全系统任一特征值实部不小于容差就为不稳定。因此报告不得只统计 `openLoopStable`，必须输出特征根大小与模态归属。

## A. 第一遍：所有已接受配平点建立稳定性地图

对四条主趋势曲线中每一个有限、收敛、可信且未触限的配平点：

1. 使用当前默认差分步长调用一次 `linearize_numeric`；
2. 计算：
   - 完整 9×9 A 矩阵特征值；
   - 现有纵向子矩阵 `[u,w,q,theta]` 特征值；
   - 现有横侧向子矩阵 `[v,p,r,phi,psi]` 特征值；
3. 输出每个点：
   - `max_real_full`、`max_real_longitudinal`、`max_real_lateral`；
   - 正实根数量；
   - 主导根实部、虚部、自然频率、阻尼比；
   - 若实部为正，输出增长时间常数 `tau_growth=1/real(lambda)`；
   - 归一化右特征向量和参与状态排序；
   - 中性根数量。

分类规则：

- `abs(lambda) <= 1e-6`：运动学/航向中性根，单独记录，不算不稳定；
- `1e-6 < real(lambda) <= 1e-3`：近中性或数值敏感正根，不直接作物理结论；
- `real(lambda) > 1e-3`：候选开环不稳定根；
- 不得只引用 `openLoopStable` 布尔值。

按模式统计：

- 有效配平点总数；
- 含候选正根的点数和百分比；
- 纵向不稳定点百分比；
- 横侧向不稳定点百分比；
- 主导正根实部的最小值、中位数、最大值；
- 最大增长时间常数和最短增长时间常数；
- 不稳定区间是否连续。

必须生成：

- `nuaa_stability_map.csv`
- 四模式 `max(real(lambda))` 随速度变化图；
- 纵向/横侧向分别的稳定性覆盖图。

## B. 第二遍：只对需要复核的点做三步长检查

为控制计算量，不对所有点重复三次线性化。以下点使用差分步长比例 `0.5, 1, 2`：

1. 第一遍中所有 `real(lambda)>1e-3` 的点；
2. 每个连续不稳定区间的首点、中点和末点；
3. 每个由稳定转为不稳定或由不稳定转为稳定的边界两侧点；
4. 每个模式至少一个稳定点；
5. 直升机 9 m/s 分支不一致区的点。

若不稳定点过多，避免对每点三步长重复：

- 全部点保留默认步长地图；
- 每个连续区间按首/中/末和边界点进行三步长复核；
- 另随机均匀选取不超过 5 个区间内部点；
- 在报告中明确三步长复核覆盖率。

稳健性判据：

- 正实部在三个步长下都存在；
- 模态可按特征值距离和参与状态一致匹配；
- 实部与虚部变化不超过 `max(5%,1e-3)`；
- 配平可信且线性化扰动未跨越限幅、硬切换或分支边界。

满足时标记 `ROBUST_OPEN_LOOP_INSTABILITY`；否则标记 `NUMERICALLY_SUSPECT`。

## C. 合理性判断必须按模式和模态拆分

### 1. 直升机模式

大范围开环不稳定可以合理。南航文章悬停点同时出现：

- 纵向发散共轭根；
- 横侧向正实根；
- 需要飞控增稳。

但仍需检查当前模型的不稳定根是否随速度连续、三步长稳健，且参与状态具有可解释性。

### 2. 转换模式

较大范围存在开环不稳定也可能合理，因为旋翼与固定翼气动贡献在转移，且当前模型无闭环飞控、无动态入流、干扰模型有限。

如果不稳定根在短舱角和速度方向连续变化，可作为低阶模型的开环特性；若根突然跳变、符号随步长变化或与配平分支跳变重合，则优先判为数值/模型结构问题。

### 3. 固定翼模式

必须区分：

- 纵向稳定、仅一个慢横侧向正实根：可能合理；南航 100 m/s 固定翼结果本身包含 `+0.3028` 横侧向实根，虽称总体稳定性明显更好；
- 70–150 m/s 大部分点均有慢横侧向/螺旋不稳定：可以与低方向稳定性、垂尾/方向舵有效性或几何简化相容，但应标记为待校准；
- 固定翼纵向在大部分区间出现明显正实根或发散共轭根：与南航固定翼纵向稳定结论不相容，应暂停“趋势验证完成”的结论，审查 CG、机翼/平尾气动中心、平尾导数、`Cm_alpha` 假设和线性化连续性；
- 所有模式都出现相近的强正根：高度可疑，优先检查惯量、符号、状态方程和线性化。

### 4. 增长率必须参与判断

不得把 `+1e-5 1/s` 与 `+1.0 1/s` 都笼统称为相同程度的不稳定。

报告至少采用：

- `0 < real(lambda) <= 1e-3`：近中性；
- `1e-3 < real(lambda) <= 0.05`：很慢不稳定；
- `0.05 < real(lambda) <= 0.3`：慢到中等不稳定；
- `real(lambda) > 0.3`：明显不稳定。

这些区间仅用于解释，不是修改参数的自动阈值。

## D. 对配平趋势任务的影响

- 开环不稳定不妨碍求得数学配平点，也不自动阻止绘制静态配平趋势；
- 但如果大面积不稳定来自数值可疑根、配平不可信或硬切换，则相关趋势不能作为可信验模证据；
- 如果是稳健、可解释的开环模态，趋势仍可报告，但必须明确该模型需要飞控增稳，不能直接用于无控制时域飞行；
- 后续操纵品质、PIO 或频域判据必须建立在稳定闭环模型上。

## E. 报告必须先回答的核心问题

在宣布软件“准备好做配平趋势”前，必须回答：

1. 大面积不稳定是否真实存在；
2. 覆盖哪些模式、速度区间和百分比；
3. 主要是纵向还是横侧向；
4. 主导根增长率有多大；
5. 三步长下是否稳健；
6. 是否由少量慢横侧向根导致全系统布尔标志大面积为 false；
7. 与南航悬停和固定翼 100 m/s 模态是否定性相容；
8. 是否影响当前静态配平趋势验证的可信度。

不得在得到上述地图前写出“大面积不稳定合理”或“不合理”的最终结论。

# 控制阶跃幅值核查

默认直接物理控制阶跃为 0.5°。在 75°/80 m/s 代表点，0.5° 差动总距试算触发 `control_stability:StepLeavesPhysicalBranch`，因此该幅值不进入正式响应结果。

随后在同一配平状态、同一默认参数和同一 0.01 s 时间步下执行 0.25°、0.10°、0.05° 递减核查。首个 0.25° 试算即满足全时段左右旋翼物理闭合；同一点尚未执行的差动纵向周期变距和对称纵向周期变距也用同一递减序列核查，0.25° 均满足物理闭合。

因此正式阶跃采用：

|工况|通道|幅值|依据|
|---|---|---:|---|
|15°/20 m/s|全部六通道|0.5°|默认小扰动|
|45°/35 m/s|全部六通道|0.5°|默认小扰动|
|75°/80 m/s|elevator、aileron、rudder|0.5°|默认小扰动且物理闭合|
|75°/80 m/s|diffCollective、diffCyclic、cyclicLong|0.25°|0.5° 差动总距失败后递减核查；0.25° 全部物理闭合|

该调整没有改变控制限位、旋翼分支判据、默认参数或生产物理模型；失败试算被保留，不用较小幅值掩盖 0.5° 差动总距不受支持的事实。

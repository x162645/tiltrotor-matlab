# 通用低阶倾转旋翼模型分层外部验证与可信适用域：主线综合

## 1. 研究对象与核心问题

本项目研究对象是一个具有明确低阶假设的通用倾转旋翼飞行动力学模型。XV-15 在本研究中的角色是提供公开、可追踪且覆盖多个证据层级的外部参照，而不是要求模型被反向调整为 XV-15 数字孪生。

因此，研究的核心问题并不是：

> 如何把低阶模型的 XV-15 误差调到很小？

而是：

> 在不利用验证目标反调模型的条件下，一个通用低阶倾转旋翼模型能够在哪些物理层级、工况范围和预测量上得到外部证据支持；哪些来源受约束的物理增强具有跨数据集的可泛化改善；仍无法闭合的偏差和证据缺口如何转化为可信适用域边界？

整个项目固定遵循：

`模型身份冻结 -> 外部验模 -> 失败保留 -> 机理诊断 -> 新模型身份 -> 再冻结 -> 独立/跨设施外部检验 -> 可信域 -> 下一证据层级`

这一顺序是本研究与普通“调参相关性”工作的核心区别。

## 2. M0：先验通用低阶模型必须首先接受失败

冻结 M0：

- 分支：`frozen/m0-xv15-hover-v1-20260828`；
- 提交：`27f40883633ca14acc0e928649b62d7abb855491`；
- production rotor path：`model/rotor_model_bemt.m`。

M0 保留通用低阶截面气动、等效几何表达和概念性质量分布，不要求每一个 generic 参数都来自 XV-15。XV-15 验证实例只映射当前模型已经消费且能够由公开资料闭合的几何和试验输入。

OARF original-metal-blade Run 15 在固定 6-11 deg 区间的 MATLAB R2021a 外部相关结果为：

- CT MAPE = 56.4224%；
- CP MAPE = 62.6130%；
- FM MAPE = 23.0180%。

Run 14 得到相似残差：

- CT MAPE = 56.1864%；
- CP MAPE = 64.0809%；
- FM MAPE = 19.1169%。

这两个结果没有被解释为“模型必须立即修到通过”，而是冻结为 M0 的外部证据：

1. 在已经支持的约 6-11 deg 区间，模型能够得到稳定的正推力物理解；
2. CT、CP 随总距增加的定性趋势正确；
3. 绝对 CT/CP 存在约 50%-65% 的系统性低估；
4. 低总距还存在物理分支/求解限制；
5. M0 因而不能称为 XV-15 定量悬停性能模型。

这一步建立了全文最重要的基线：**低阶模型的失败本身是结果，而不是需要隐藏的问题。**

## 3. 从“误差”转向“误差来源”，但不反求验证目标

M0 失败后，研究没有直接对 CT/CP 做线性增益、总距偏置或参数优化，而是建立来源分层的物理诊断。

### 3.1 截面气动

公开 C81 参考模型输入约化表明，generic M0 的截面气动与 XV-15 参考气动存在显著差异。将来源受约束的 C81 类气动引入分析层后，Run 15 误差由：

- CT 56.42% -> 42.87%；
- CP 62.61% -> 51.12%；
- FM 23.02% -> 12.22%。

因此二维截面气动是一个被实际计算证实的重要误差来源，但不是全部误差来源。

### 3.2 实际径向几何

M0 将 XV-15 原始金属桨弦长和非线性扭转约化为常弦/单参数线性扭转。M1-A 恢复公开径向弦长和非线性扭转，并配合标量 C81 后，Run 15 CT/CP MAPE 进一步降至约 33.95%/45.24%。

但更完整的径向/马赫 C81（M1-B）反而得到 37.85%/50.52%。这说明：

> 更小的相关误差不能自动等同于更高的物理真实性。

M1-A 的更小误差可能包含模型误差抵消。因此本研究没有按 Run 15 MAPE 直接挑选“最好看”的模型。

### 3.3 环带动量

M1-C 在 M1-B 上增加分环带动量后，CT/CP MAPE 改善到 35.75%/47.90%，只有约 2-3 个百分点变化。

因此独立径向环带入流能够影响结果，但不足以解释主要剩余误差，而且不能被包装成非局部尾迹模型。

### 3.4 受载扭转

NASA 参考结构模型允许构造来源受约束的准静态受载扭转诊断。计算得到的主要受载扭转方向会降低有效桨距并使当前低估进一步恶化。

因此，现有来源证据不支持通过假设“真实受载桨距比报告总距高若干度”来解释主要残差。未知的正总距偏置没有被从 OARF 误差中反求出来。

### 3.5 旋转失速延迟

Felker 等公开研究指出，高扭转倾转旋翼内段可能在超过二维失速范围时仍维持高升力附着流，因此二维 C81 直接查表可能在高载荷内段过于保守。

M1-E 只测试预声明的来源角色：

- generic Corrigan n=1；
- 文献中已经用于 XV-15/OARF 相关性的 Koning n=1.8。

n=1 的 M1-E-1 得到：

- CT MAPE = 32.7287%；
- CP MAPE = 45.8916%；
- FM MAPE = 7.5923%。

n=1.8 虽然 CT/CP 更小，但它本身来自 XV-15/OARF 相关性研究，因此被明确标记为非独立复现，不能作为最终 holdout 模型。

## 4. M1-F：非局部尾迹有作用，但不允许因局部改善而晋升

在 M1-E-1 之后，建立了规定 Landgrebe 尾迹 + 离散尾涡 + 有限段 Biot-Savart 非局部诱导诊断。

正式 MATLAB 和数值闭合审计表明：

- 7-11 deg 存在稳定非局部尾迹固定点；
- CT/CP 相对 M1-E-1 可再改善若干个百分点；
- 10 deg 的尾迹转数/离散敏感性明显小于当前模型误差；
- 但 6 deg 出现负功率和极端正负径向诱导速度，即使数学固定点可收敛也不具有可接受的物理意义。

同时，经典 Landgrebe 数据库对 XV-15 这类高度扭转桨叶存在已知适用性限制，当前内段尾迹几何还是明确标记的假设推广。

因此 M1-F 被保留为：

`MODEL_FORM_DIAGNOSTIC`

而没有因 7-11 deg 的局部改善晋升为最终 M1。

这一步体现了本研究的方法学原则：**数值更接近试验不是晋升模型身份的充分条件。**

## 5. 在 WADC 之前冻结 M1，而不是看完 WADC 再选

进入不同设施数据之前，提交：

`d313296a35319dc8a5e6c398adbed0d54e0f8ede`

正式冻结：

`M1_HOLDOUT_V1 = M1_E1_GENERIC_CORRIGAN_N1`

其模型身份包括：

- XV-15 original-metal-blade 实际径向弦长；
- 非线性扭转；
- 四段 C81 + 局部 Mach/alpha；
- generic Corrigan-Schillings n=1；
- 冻结 M1-E-1 的全盘标量动量闭合和既有一阶方位入流形状；
- 当前低阶一阶谐波挥舞。

冻结后不允许：

- 根据 WADC 改 n；
- 改 C81；
- 改几何；
- 改 total-collective mapping；
- 加 CT/CP/FM gain；
- 用 WADC Mtip 反调 aSound；
- 根据 WADC 误差选择其他 M1 阶段。

后续发现冻结文档曾把入流描述简写为“均匀动量”，只进行了文档与既有实现的一致性修订。Stage-5 runner 对冻结 Stage-3 M1-E-1 六个 OARF 点进行等价性检查，CT/CP/FM 最大绝对差为 0，证明没有在 WADC 后改变模型实现。

## 6. WADC：真正检验“改善是否泛化”，而不是检验“能不能调得更准”

WADC formal Run 1-3 来自另一试验设施，并覆盖典型 Mtip 约：

- 0.53；
- 0.62；
- 0.66。

验证窗口继承冻结前 6-11 deg 支持范围。由于源数据在该区间没有 7 deg，只使用实际存在的：

`6, 8, 9, 10, 11 deg`

每 Run 5 点，共 15 点；没有插值，也没有按误差删除点。

正式 MATLAB R2021a 结果：

### M0 pooled

- CT MAPE = 59.1465%；
- CP MAPE = 66.0974%；
- FM MAPE = 23.0497%。

### 冻结 M1 pooled

- CT MAPE = 37.8956%；
- CP MAPE = 51.1078%；
- FM MAPE = 9.2559%。

### M1 相对 M0

- CT 改善 = 21.2509 pp；
- CP 改善 = 14.9896 pp；
- FM 改善 = 13.7938 pp。

更重要的是，三个不同尖端马赫数 Run 的改善量高度一致：CT 都约 21.2 pp，CP 都约 15.0 pp。

这意味着：

> 来源受约束的 M1 物理增强并非只在 OARF Run 15 上得到偶然相关性；其改善方向在另一设施和更低尖端马赫数下仍然保持。

但这并不意味着 M1 已经准确：WADC 上 CT/CP 仍约 38%/51% MAPE，且继续系统性偏低。

因此最严谨的结论是：

> M1 显著降低了能够跨设施复现的一部分模型形式偏差，但没有消除控制绝对推力和功率水平的主要剩余误差。

## 7. 当前悬停可信适用域

基于 OARF + WADC，可以把“模型是否可信”从二元判断拆成预测量和工况相关的可信域。

### 7.1 可以支持的声明

在 original-metal-blade 悬停、约 6-11 deg、Mtip 约 0.53-0.69 的已验证证据范围内：

- M0/M1 能够表示 CT、CP 随 collective 增加的基本趋势；
- M1 相对 M0 的误差降低方向具有跨设施支持；
- M1 的来源受约束物理增强具有可泛化价值；
- FM 可作为中等可信度的效率诊断量使用，但必须同时报告逐点误差，避免平均有符号误差抵消。

### 7.2 不允许支持的声明

当前证据不支持：

- M1 是 XV-15 数字孪生；
- M1 可高精度预测绝对 CT；
- M1 可高精度预测绝对 CP；
- collective < 6 deg 属于可信域；
- 因 WADC 有更高 collective 数据就把可信域自动扩展至 >11 deg；
- 将 Mtip 0.53-0.69 之外的工况视为已验证；
- 将悬停组件验证结果外推为完整前飞飞行动力学验模通过。

## 8. 动态层：证据存在，但没有 HIGH-homology 案例

在完成悬停可信域后，研究回到整机飞行动力学主线，而不是继续用悬停数据堆叠模型复杂度。

TM-86009、TM-89428、hover identification publication 和 CR-177406 Vol. III 的来源复核表明，真实 XV-15 动态响应证据确实存在：

- cruise q/elevator；
- cruise az/elevator；
- cruise p/aileron；
- cruise beta/rudder；
- hover frequency responses；
- step-response flight data；
- hover-to-cruise multiple flight conditions。

然而，当前公开且已核实资料仍没有为至少一个具体动态记录同时闭合：

- matched test weight；
- CG；
- inertia tensor；
- rotor RPM / governor state；
- exact atmosphere；
- complete control-chain mapping；
- machine-readable matched raw inputs/outputs。

特别是 cruise az/elevator 源文献本身指出 rotor-RPM dynamics 是一个重要未建模因素，而当前仓库没有与该试验同源的 engine/governor state。

因此动态证据矩阵最终为：

`BLOCKED_NO_HIGH_HOMOLOGY_CASE`

没有运行所谓“XV-15 动态验模”去制造漂亮曲线。

这不是软件能力不足。仓库已有 trim、linearization、state-space、modal 和 time-response 计算能力。真正的阻塞项是：**公开外部试飞证据无法与当前第一性低阶模型形成足够严格的同一案例输入合同。**

## 9. 这一 BLOCKED 结果为什么属于主线成果

如果为了让论文形式完整而使用 generic XV-15 weight、CG、inertia、RPM、standard atmosphere 和假设 control gain，得到的只是：

`XV-15-like parameterized simulation`

而不是：

`matched-condition external dynamic validation`

本研究选择保留 BLOCKED，因此可以清楚区分：

- 模型代码“能不能算”；
- 外部证据“够不够资格验”。

这种区分本身正是模型可信性研究的核心。

## 10. 总体验证矩阵的最终研究结论

截至当前阶段，证据链可以浓缩为：

### 第一层：模型结构与数值执行

M0 生产计算路径已冻结并审计；数值离散误差远小于主要外部残差。

### 第二层：组件外部验证

OARF Run 14/15 表明 M0 有稳定的定性趋势，但绝对 CT/CP 严重低估。

### 第三层：来源受约束的模型形式研究

截面气动、真实径向几何和旋转失速延迟均被证明能够显著改变预测；某些更复杂处理并不一定进一步降低误差，揭示模型误差抵消和低阶结构限制。

### 第四层：新模型冻结

M1_HOLDOUT_V1 在读取 WADC 数值前冻结；没有根据 holdout 改参数。

### 第五层：跨设施外部验证

WADC Run 1-3 表明 M1 相对 M0 的明显改善跨设施和多个 Mtip 保持，但绝对 CT/CP 仍明显偏低。

### 第六层：可信适用域

M1 可以被称为比 M0 更可信的低阶悬停预测模型，但只能在已验证工况内作趋势、相对变化和有限效率诊断；不能被称为高精度 XV-15 悬停性能模型。

### 第七层：整机动态外部验证门槛

已有公开飞行响应不足以形成至少一个 HIGH-homology matched-condition case，因此动态定量验证保持 BLOCKED。

## 11. 可形成的论文核心贡献

在不夸大当前模型精度的前提下，项目已经形成三个可独立成立的研究贡献。

### 贡献 1：一种面向低阶倾转旋翼模型的分层外部验证方法

不是用单一相关曲线决定模型“正确/错误”，而是建立模型身份、数据角色、证据独立性、参数来源、数值验证、物理机制诊断和可信域之间的可审计链路。

### 贡献 2：XV-15 原始金属桨上来源受约束物理增强的跨设施泛化证据

M1 在 WADC 三个不同尖端马赫数系列中稳定降低 M0 的 CT、CP、FM 误差，说明改善不是 Run 15 单数据集拟合造成的。

### 贡献 3：明确低阶模型的能力边界，而不是隐藏失败

研究不仅报告“哪里改善”，也明确报告：

- CT/CP 绝对定量误差仍大；
- 低 collective 不在可信域；
- 非局部尾迹首轮模型在低载荷出现病态解；
- 整机动态层因外部证据同源性不足保持 BLOCKED。

因此论文的核心不是“低阶模型已经足够精确”，而是：

> **在来源可追踪、禁止目标反调和跨设施验证的约束下，可以定量识别低阶倾转旋翼模型哪些物理增强具有可泛化价值，并为仍受模型形式或外部证据限制的区域建立明确可信边界。**

## 12. 当前停止点与未来工作的合法边界

当前 M1 主线在悬停层已经达到一个合理停止点。继续使用 OARF 或 WADC 调整 M1_HOLDOUT_V1 会破坏 post-freeze 验证价值。

未来只有两类合法扩展：

1. **M2 物理层级**：例如更可靠的倾转旋翼自由尾迹/升力线/结构耦合模型，但必须建立新的模型身份和新的开发/验证数据分割；
2. **动态 HIGH-homology 证据闭合**：取得 CR-177406 或其他原始试飞卷册中的同一案例 weight/CG/inertia/RPM/atmosphere/control-chain/raw-response 记录后，先冻结输入映射，再执行动态外部验证。

在上述任一条件未满足之前，不应继续通过目标数据调节现有 M1，也不应制造名义上的整机动态验证。

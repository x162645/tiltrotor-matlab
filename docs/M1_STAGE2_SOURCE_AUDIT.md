# M1 第二阶段来源审计：XV-15 受载桨距与弹性扭转

## 结论

第二阶段所需的结构与气动力矩输入已经能够从公开 NASA XV-15 参考模型中闭合到足以开展**来源约束的准静态受载扭转诊断**，但不能闭合到“1985 年 OARF Run 14/15 同一试验记录的直接实测结构参数”这一更强证据等级。

因此 M1-D 的正确身份是：

`SOURCE_CONSTRAINED_QUASISTATIC_LOADED_TORSION_DIAGNOSTIC`

而不是 XV-15 全气弹性数字孪生，也不是 OARF 记录级结构复现。

## 1. 公开参考模型确实包含扭转和控制柔度

NASA/TP-2004-212262 在 Rotor Model 部分明确说明，原始 XV-15 钢桨在 CAMRAD II 中按每片桨叶两个弯曲模态、一个扭转模态和柔性变距拉杆建模。

来源：NASA/TP-2004-212262，正文 Rotor Model，PDF p.9 / 报告正文附近。

报告在 Control-System Stiffness 部分进一步明确给出：叶片所见的基准桨距刚度为 **22,400 ft-lb/rad**。

Appendix A 的结构输入也给出 `KPL=22400.`，同时列出 51 个 `RPROP` 径向站、`XQC` 和 `GJ` 分布。

因此，受载桨距变化并不是为了修正 OARF 误差临时发明的机制，而是 XV-15 公开综合分析模型中明确存在的结构自由度。

## 2. GJ 径向分布

Appendix A 给出的 51 点 GJ 从根部约 410,000 lbf·ft² 逐步下降到桨尖约 4,310 lbf·ft²。M1-D 将这些原始表值逐点保存，并按

`1 lbf·ft² = 4.4482216152605 × 0.3048² N·m²`

转换为 SI 单位。

不对 GJ 乘任何经验倍率，也不根据 OARF 结果寻找“最佳刚度”。

## 3. 四分之一弦位置与力矩符号

报告 nomenclature 明确规定：

- `QC`：桨叶四分之一弦位置，相对弹性轴**向后为正**；
- `AC`：气动中心位置，相对弹性轴**向后为正**。

Appendix A 的 `XQC` 从内段负值逐渐跨过零，在约 0.75R 附近由前方转到后方，与正文“QC 线在 75%R 与桨距轴相交”的描述一致。

M1-D 在运行前固定以下符号约定：

- 正弹性扭转：增大局部几何桨距；
- 正法向气动力作用在弹性轴后方的正 `XQC` 上时，形成低头力矩，因此记为负扭转力矩；
- C81 正俯仰力矩系数按正抬头力矩处理。

该符号不允许根据 OARF 误差方向事后翻转。

## 4. C81 俯仰力矩

NASA/TP-2004-212262 Appendix A 的每个 C81 区段依次包含升力、阻力和俯仰力矩系数表。第一阶段程序只读取了 CL 和 CD；第二阶段新增 `analysis/xv15_c81_moment_lookup.m`，单独读取同一四区段的 CM 表。

该函数的迎角网格与现有 CL/CD helper 一致，保持四个径向区段和局部马赫数插值，不引入 OARF 输出。

## 5. M1-D 准静态结构关系

M1-D 对每个径向单元计算：

1. C81 四分之一弦俯仰力矩；
2. 法向气动力通过 `XQC` 相对弹性轴偏置形成的附加扭矩；
3. 从桨尖向根部积分得到内部扭矩；
4. 由 `dθ/dr = T/GJ` 积分得到桨叶结构扭转；
5. 由总气动扭矩除以 `KPL` 得到控制系统整体桨距柔度；
6. 将受载扭转反馈到局部迎角并与诱导速度、挥舞一起迭代到收敛。

程序同时保留四种配置：

- M1-B 刚性参考；
- 仅 GJ 柔性；
- 仅控制系统柔性；
- GJ + 控制系统全参考柔性。

因此可以区分桨叶自身扭转与控制链柔度各自的影响，不需要修改刚度来匹配数据。

## 6. 证据限制

NASA/TP-2004-212262 Appendix E 明确指出该 CAMRAD II XV-15 旋翼模型存在已知缺陷，其中最重要的是旋翼模型源自较老的 CAMRAD 模型并基于**预生产桨叶数据**；控制系统运动学也没有准确描述 XV-15 旋翼上方的 collective/cyclic mixer（spider），而使用了传统下置旋转斜盘表示。

报告还说明当时正在开发基于生产桨叶数据、具有更好径向分辨率和更真实上置控制系统的新模型。

因此：

- GJ、XQC、KPL 可以作为公开来源约束的结构模型输入；
- 它们不能被称为 OARF Run 14/15 的逐点直接测量值；
- 如果 M1-D 能改善误差，只能说明“这一公开结构物理机制具有解释力”；
- 如果 M1-D 作用很小或使误差恶化，也不能由此否定真实 XV-15 生产桨叶所有气弹性效应，只能排除**当前公开参考结构包下的准静态扭转**为主要解释。

## 7. 后续尾迹门槛

第一阶段已经表明独立环带动量只能小幅改善剩余残差。如果 M1-D 仍不能解释主要 CT/CP 偏差，则下一阶段应研究真正的非局部有限叶片尾迹，包括规定螺旋尾迹、升力线和 Biot-Savart 诱导，而不是重新增加 Prandtl、Mangler 或经验入流增益。

任何尾迹参数仍必须来自外部文献、几何与守恒关系，不得按 OARF 结果反调。

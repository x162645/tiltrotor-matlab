# 电子书方法索引与模型升级优先级

## 1. 决策

当前阶段暂停继续扩展 GUI，优先处理物理模型、配平定义、数值可信度和可替换接口。

本项目保持为开环飞行器本体模型。当前不引入 SCAS、自动驾驶、姿态反馈、角速度反馈或其他闭环飞控。本文所称“操纵分配”指配平问题中的执行器选择、机械/开环混合或附加约束，不等同于飞控控制律。

配平方法采用用户提供电子书的通用思路：

1. 明确飞行条件和需要配平的自由度；
2. 明确可参与配平的执行器；
3. 使独立未知量数与独立约束数匹配；
4. 多个执行器作用于同一自由度时，使用明确的机械/开环分配关系或固定其中部分执行器；
5. 通过 Jacobian、限幅和完整状态导数检查解的可行性；
6. 真实型号混控、几何、气动和功率数据不足时，只建立接口，不填入伪造的型号数值。

南航文章继续用于倾转旋翼机部件划分、固定短舱角代表工况、坐标和部件力/矩链路参考。NASA 等原始资料用于后续型号参数核验。电子书用于通用建模方法、数值算法、配平组织、旋翼与干扰模型层级选择。

## 2. Codex 用量与文献读取规则

电子书约 622 页，不交给 Codex 全书阅读。文学检索、章节筛选、公式解释、适用范围判断和优先级制定由 ChatGPT 完成。

Codex 每个任务只允许读取：

- `AGENTS.md`；
- 当前 `CODEX_TASK.md`；
- 本文；
- 与当前工作包直接相关的少量代码和测试；
- ChatGPT 为该工作包准备的短篇“方法包”。

除非 `CODEX_TASK.md` 明确指定，Codex 不得扫描整本电子书。若必须查看原页，只给出一个很小的页码范围，并要求只读取指定公式、图或表。

后续建议为每个物理工作包建立一个短文件，例如：

```text

docs/ebook_packets/INFLOW_SOLVER_PACKET.md
```

每个方法包只保留：公式、符号、坐标约定、适用假设、代码映射、禁止推断项和验收测试。Codex 不负责再次从 622 页 PDF 中寻找方法。

## 3. 电子书提供的主要优化思路

### 3.1 配平与数值求解

电子书相关内容：配平自由度选择、操纵匹配、连续修正、Newton/Jacobian、中心/前向/后向差分、周期配平和旋翼特殊配平。

可用于当前项目：

- 通用配平定义；
- 直升机、转换、飞机模式采用不同执行器集合；
- 配平 Jacobian、秩、奇异值和条件数；
- 限幅附近使用单边差分；
- 配平结果回代完整九状态导数；
- 多个执行器参与同一俯仰自由度时增加明确分配约束。

### 3.2 操纵分配

电子书相关内容：机械、电机械、液压机械或数字混合装置；旋翼周期变距与升降舵随主轴/短舱角连续交接；线性、半线性和余弦示例函数。

可用于当前项目：

- 开环执行器分配接口；
- 直升机端以旋翼周期变距为主；
- 飞机端以升降舵为主；
- 转换区使用连续函数，避免硬切换；
- 当前程序角度定义为 `betaM=0` 直升机、`betaM=90 deg` 飞机；电子书主轴角若采用相反定义，必须先转换。

电子书示例函数只能作为概念分配方案，不能声称为 XV-15 实际混控律。

### 3.3 诱导速度求解

电子书相关内容：固定点/平均迭代、Newton-Raphson、二分法、多根、下降状态和动态入流选项。

可用于当前项目：

- 为现有均匀准稳态入流建立显式残差；
- 保留当前松弛迭代作为快速路径；
- 失败后使用有区间保障的二分法；
- 输出求解方法、区间、迭代次数、残差和选根原因；
- 暂不声称支持涡环、反流、自转或风车制动状态。

当前阶段不要求采用动态入流。

### 3.4 质量、重心和惯量

电子书相关内容：部件质量构成、部件自身惯量、坐标旋转、平行轴定理、总重心和总惯量合成。

可用于当前项目：

- 将移动质量半径和桨毂几何半径分开；
- 建立固定机体、左右短舱、左右旋翼/桨毂等部件的质量属性接口；
- 由部件构成计算随倾转角变化的 CG 和惯量；
- 保留旧的等效 `I0/KI` 模型作为兼容路径，直到真实部件参数可靠。

### 3.5 旋翼叶素与翼型数据

电子书相关内容：完整叶素局部速度、桨距与扭转、翼型升阻力查表、宽迎角示例、马赫数和雷诺数依赖、叶素力矩积分。

可用于当前项目：

- 建立 `c(r)`、`twist(r)`、`airfoilID(r)` 接口；
- 建立 `CL/CD/Cm(alpha,M,Re)` 查表接口；
- 用书中示例数据测试插值和宽迎角连续性；
- 保留现有解析极曲线作为 fallback。

书中示例翼型不能直接当作目标旋翼真实翼型。

### 3.6 挥舞与桨毂约束

电子书相关内容：一阶谐波挥舞、桨叶质量积分、铰偏置、挥舞弹簧、阻尼、预锥、delta-3、下悬量和准静态挥舞改进。

可用于当前项目：

- 核对现有稳态一阶谐波挥舞；
- 增加铰偏置、弹簧、阻尼、预锥等可选接口；
- 由真实质量分布计算一阶质量矩和挥舞惯量；
- 在参数不足时让新增效应默认关闭；
- 动态挥舞状态后置。

### 3.7 旋翼—机翼—机身—尾翼干扰

电子书相关内容：尾流方向、收缩、偏斜、下游发展、部件连接矩阵、诱导速度叠加和双向迭代闭合。

可用于当前项目：

- 建立通用尾流源/目标/连接矩阵接口；
- 逐步替换单一 `wakeFactor`；
- 先实现旋翼到对应半翼；
- 再扩展到尾翼、机身以及反向干扰；
- 机翼条带化后计算局部尾流覆盖率。

真实干扰系数和构型验证数据不足时，只实现框架或明确的概念模型。

### 3.8 发动机、传动、转速和功率

电子书相关内容：`J*dOmega/dt = Qengine - Qrotor`、一阶发动机模型、调速器、转速误差反馈和传动系统。

可用于当前项目：

- 先增加转速提供器接口；
- 输出旋翼扭矩、所需功率和功率裕度；
- 后续再增加发动机/调速器动态状态。

真实 RPM 调度、发动机功率和传动惯量仍需型号资料。

### 3.9 机翼离散和高迎角处理

电子书相关内容：局部来流、局部迎角、气动数据库、作用点力矩和分布式载荷思想。

可用于当前项目：

- 保留当前连续 near-normal 混合以避免数值跳变；
- 将左右半翼从集中自由流/滑流区逐步升级为展向条带；
- 每个条带计算局部速度、迎角、动压、舵面和尾流覆盖。

混合中心和宽度在没有数据时仍只能标为概念连续化参数。

## 4. 优先级排序

优先级原则：

1. 不需要新真实型号参数且能消除语义耦合、完善配平定义或提高数值可信度的任务最先；
2. 可以先搭接口、保持旧行为的任务居中；
3. 必须依赖真实几何、质量、气动、混控或功率数据的任务后置；
4. 动态入流、动态挥舞和短舱倾转动力学在当前定常配平目标下最后处理。

|-:|---|---|---|---|---|

|2|通用模式配平核心|`V,gamma,betaM,theta,collective,cyclicLong,elevator`、残差集合|无|中高|先保持开环本体|
|3|开环俯仰执行器分配约束|周期变距、升降舵、倾转角、归一化通道|概念版本无；真实传动比后置|中|不等于飞控|

## 5. 推荐实施顺序

### 第一阶段：无需新真实参数

1. 完成 Draft PR #8 的半径语义拆分；
2. 建立通用模式配平核心；
3. 加入电子书式开环俯仰执行器分配约束；
4. 加入配平 Jacobian、条件数、限幅和完整导数检查；
5. 加入线性化步长敏感性和非线性回代检查；
6. 加入诱导速度显式残差和保底求根。

### 第二阶段：接口可先行，型号数据后补

7. 扭矩/功率诊断与转速提供器；
8. 部件质量惯量框架；
9. 桨叶径向几何和翼型查表接口。

### 第三阶段：依赖真实参数或高工作量

10. 挥舞结构参数；
11. 机翼条带化；
12. 多部件尾流；
13. 真实参数替换与验证；
14. 动态短舱、动态入流、动态挥舞。

## 6. 每个工作包的交付方式

ChatGPT 在每个工作包开始前负责输出一个短方法包，至少包含：

- 使用的电子书章节和有限页码范围；
- 经过解释后的公式；
- 代码变量映射；
- 坐标和符号约定；
- 允许采用的假设；
- 禁止推断或禁止填入的真实参数；
- 最小修改范围；
- 有限的代表工况和验收测试。

Codex 只负责实现该方法包和运行规定测试，不负责重新阅读整本电子书、重新制定优先级或自行选择物理模型层级。

# 电子书方法索引与模型升级优先级

## 1. 总体决策

当前阶段继续暂停扩展 GUI，优先处理物理模型、配平定义、数值可信度和可替换接口。

项目保持为开环飞行器本体模型。当前不引入 SCAS、自动驾驶、姿态反馈、角速度反馈或其他闭环飞控。本文所称“操纵分配”只表示配平层的执行器选择与机械/开环混合，不等同于控制律。

电子书方法用于：

1. 明确飞行条件、配平自由度和可参与配平的执行器；
2. 保证独立未知量数与独立约束数匹配；
3. 多执行器作用于同一自由度时建立明确的开环分配关系；
4. 通过 Jacobian、秩、奇异值、条件数、限幅和完整状态导数检查配平可信度；
5. 在真实型号数据不足时只建立接口或明确的概念模型，不填入伪造参数。

南航文章继续用于部件划分、坐标和力/矩链路参考；NASA 等原始资料用于后续型号参数核验；电子书用于通用建模方法、数值算法、配平组织和模型层级选择。

## 2. Codex 与文献读取规则

电子书约 622 页，不交给 Codex 全书阅读。文献筛选、公式解释、适用范围判断和工作包设计由 ChatGPT 完成。

- `AGENTS.md`；

## 3. 电子书可用于当前项目的主要方向

### 3.1 配平与数值求解

相关内容：配平自由度、操纵匹配、连续修正、Newton/Jacobian、中心/前向/后向差分和旋翼特殊配平。

当前应用：

- 通用模式配平定义；
- 直升机、转换和飞机模式使用不同执行器集合；
- 配平 Jacobian、秩、奇异值和条件数；
- 边界附近使用单边差分；
- 配平结果回代完整九状态导数；
- 对低裕度工况输出明确警告。

### 3.2 操纵分配

相关内容：机械、电机械、液压机械或数字混合；周期变距与升降舵随主轴角连续交接；线性、半线性和余弦示例。

当前已经应用：

- 开环虚拟俯仰命令接口；
- 直升机端以纵向周期变距为主；
- 飞机端以升降舵为主；
- 转换区使用连续余弦权重；
- 完成电子书主轴角与项目 `betaM` 角度约定换算；
- 概念分配明确标记 `ASSUMED_CONCEPT`，不声称为 XV-15 实际混控。

### 3.3 诱导速度求解

后续应用：

- 为现有均匀准稳态入流建立显式残差；
- 保留松弛迭代作为快速路径；
- 失败后使用有区间保障的求根；
- 报告区间、迭代次数、残差和选根原因；
- 暂不声称支持涡环、反流、自转或风车制动状态。

当前不要求动态入流。

### 3.4 质量、重心和惯量

当前已经应用：

- 将移动质量半径 `RH_mass` 与桨毂几何半径 `RH_hub` 分开。

后续应用：

- 固定机体、左右短舱、左右旋翼/桨毂等部件质量属性接口；
- 部件自身惯量、坐标旋转和平行轴定理；
- 随倾转角变化的 CG 和总惯量；
- 在真实参数不足时保留旧等效模型兼容路径。

### 3.5 旋翼叶素与翼型数据

后续应用：

- `c(r)`、`twist(r)`、`airfoilID(r)` 接口；
- `CL/CD/Cm(alpha,M,Re)` 查表；
- 宽迎角连续性和插值测试；
- 现有解析极曲线作为 fallback。

书中示例翼型不能当作目标旋翼真实翼型。

### 3.6 挥舞与桨毂约束

后续应用：

- 核对现有稳态一阶谐波挥舞；
- 增加铰偏置、刚度、阻尼、预锥和 delta-3 可选接口；
- 由真实质量分布计算一阶质量矩和挥舞惯量；
- 参数不足时新增效应默认关闭；
- 动态挥舞后置。

### 3.7 多部件干扰

后续应用：

- 通用尾流源/目标/连接矩阵；
- 逐步替换单一 `wakeFactor`；
- 先实现旋翼到对应半翼；
- 再扩展尾翼、机身和反向干扰；
- 机翼条带化后计算局部尾流覆盖率。

真实干扰系数不足时只实现框架或明确概念模型。

### 3.8 发动机、传动、转速和功率

后续应用：

- 转速提供器接口；
- 输出旋翼扭矩、所需功率和功率裕度；
- 后续再增加发动机、调速器和转速动态。

真实 RPM 调度、功率和传动惯量仍需型号资料。

### 3.9 机翼离散和高迎角处理

后续应用：

- 保留当前连续 near-normal 混合；
- 将左右半翼升级为展向条带；
- 每个条带计算局部速度、迎角、动压、舵面和尾流覆盖。

混合中心和宽度在没有数据时继续标记为概念连续化参数。

## 4. 当前优先级

优先级原则：

1. 无需新真实参数、能消除语义耦合或提高数值可信度的任务优先；
2. 可先建立接口、保持旧行为的任务居中；
3. 依赖真实几何、气动、混控或功率数据的任务后置；
4. 动态入流、动态挥舞和短舱倾转动力学最后处理。

# 冻结低阶旋翼验证配置的外部相关性与误差归因

> **方法学修正（2026-08-28）**：本页保留 Codex 在 MATLAB R2021a 上完成的冻结运行数值记录，但修正此前“独立/盲 hold-out 验模”“预先指定评分区间”以及“严格停止扩模”等过强表述。OARF Run 15 已在 PR #67/#68 的模型诊断和研究方向选择中反复使用，因此本次结果应称为**开发后冻结的外部相关性比较**，不能再称为严格盲验证。证据等级以 `docs/XV15_ERROR_ATTRIBUTION.csv` 与 `docs/XV15_CODEX_HANDOFF_AUDIT.md` 为准。

## 结论

当前低阶旋翼验证配置在自身方程、单位和数值闭合方面可以自洽，但在参数冻结后与 XV-15 OARF Run 15 比较时，**绝对量级相关性明显不足**。

固定报告窗口 6° 至 11° 内，六个点全部物理收敛：

| 指标 | 平均绝对百分比误差 | 平均有符号误差 | 判断 |
|---|---:|---:|---|
| 推力系数 CT | 42.8716% | -42.8716% | 系统性低估 |
| 功率系数 CP | 51.1184% | -51.1184% | 系统性低估 |
| 悬停效率 FM | 12.2221% | -11.8414% | 大部分点低估 |

0°、2°、4°三个低载荷点没有得到物理解，已作为适用范围失败保留在逐点表中，没有用缺失值掩盖，也没有并入固定报告窗口。

这里的 6° 至 11°是**此前诊断已经建立的物理支持区间**，现在把它冻结为固定报告窗口；它不是在看到模型行为之前预注册的 blind/predeclared window。

这组结果支持的结论是：

> **生产核心方程不变、启用 opt-in 截面气动适配层的冻结低阶验证配置，不能定量复现 XV-15 原始金属桨 OARF Run 15 的绝对推力和功率。**

它不证明动量理论或叶素法本身错误，也不能单独识别剩余误差究竟来自哪个未建模物理机制。它同时意味着两类做法都不允许：

1. 不允许为了贴合 OARF 任意增加经验增益、损失因子或反调参数；
2. 也不能因为当前归因尚未闭合，就预先禁止独立、文献约束的模型形式诊断。

后续原始资料追溯已经闭合逐点密度，建立了相容的来源质量属性包，并明确了 C81 的通用参考弦语义；这套 XV-15 表的专用弦线偏置仍未闭合。质量属性的 10°耦合替换在数值噪声内未分辨出 CT/CP/FM 变化，但显著改变平均锥度。最新状态见 `docs/XV15_SOURCE_CONTRACT_CLOSURE.md`。

## 外部相关性边界

本次冻结运行遵守以下计算边界：

- 不修改 `model/rotor_model_bemt.m`、`params_nominal.m` 或其他 production 默认路径；
- 使用 `rotor_model_bemt_section_aero` 这一 opt-in 适配层，把独立 NASA C81 约化参数映射到现有低阶旋翼方程；
- 每个试验点只做一次冻结配置计算；
- 不进行 OARF 驱动的参数拟合、经验增益扫描或评分窗口搜索；
- runner 内先求出预测，再接入 OARF CT/CP/FM 进行误差计算，因此**同一次运行没有直接用目标值迭代反调参数**；
- 但由于 OARF Run 15 已在此前 PR 中参与误差诊断和模型选择，这一点不能恢复数据集层面的 blind hold-out 独立性；
- 声明对象是“冻结低阶验证配置”，不是 XV-15 高保真重建模型。

正式冻结编号保留为 `XV15_LOW_ORDER_HOVER_V1_20260825`，入口为 `analysis/run_xv15_frozen_low_order_validation.m`。保留原编号是为了不改写历史 MATLAB 运行记录；本次只修正方法学解释。

## 冻结参数及其意义

这些调整用于把公开输入翻译成当前低阶模型可以接收的形式，不是为了让输出靠近 OARF。

| 项目 | 冻结值或做法 | 意义 |
|---|---|---|
| 半径、叶片数、根切 | 3.81 m、3、0.0875R | 直接采用公开几何 |
| 弦长 | 0.3623849 m | 实际变弦长按面积守恒约成常弦长 |
| 扭转 | 桨尖等效扭转 -36.3479° | 公开非线性扭转约成线性扭转，并锚定 0.75R 总距 |
| 截面气动 | 独立 C81 表约化得到五个标量 | 替代通用翼型参数；不使用 OARF 性能结果拟合这五个量 |
| 径向、方位离散 | 12、16 | 保持 production 默认值 |
| 桨叶质量与惯量 | 45 kg 通用均匀分布假设 | V1 冻结运行的历史假设；后续已有来源质量包单点核验 |
| 空气密度 | 1.225 kg/m³ | V1 冻结运行的标准大气假设；后续资料追溯已得到 Run 15 逐点约 1.226–1.227 kg/m³ |

需要强调证据等级：此前“通用截面参数 → C81 标量参数”的误差改善量中，旧通用基线来自方程级 `PREVIEW`，而本页 C81 冻结配置来自 MATLAB 实跑。因此 56.4224%→42.8716%、62.6130%→51.1184%、23.0180%→12.2221% 可以作为**诊断量级**说明截面参数重要，但不能直接当成完全同证据等级的正式误差预算。若论文需要严格比较，应在同一 MATLAB runner 内重新计算两套配置。

实际径向几何、完整 C81、环带动量、Mangler、delta3、旋转增升等历史结果仍有一部分是方程级 `PREVIEW`。它们可以支持诊断方向，但不能写成“MATLAB 已验证”，详见 `docs/XV15_ERROR_ATTRIBUTION.csv`。

## 已闭合的试验口径

### 功率定义不是当前主因

NASA/TM-86833 定义 CP 等于 CQ。因为叶尖速度等于角速度乘半径，代码使用的 `Q×角速度/(空气密度×盘面积×叶尖速度³)` 与试验修正扭矩系数在代数上同构。试验还扣除了传感轴与旋翼之间两个轴承的扭矩，并把结果称为实际旋翼扭矩。Run 15 所选点风修正约 0.5%至0.7%，远小于当前约 51%的 CP 误差。[NASA/TM-86833](https://ntrs.nasa.gov/citations/19860005773)

NASA/CR-2017-219486 表 A-2 中 CP 数值与原试验报告修正 CQ 逐项相同，因此当前比较不是把发动机功率、齿轮箱输入功率或未扣轴承损失的功率误当成旋翼功率。[NASA/CR-2017-219486](https://ntrs.nasa.gov/citations/20180000109)

仍未闭合的是完整系统余量以及旋转毂/桨毂气动阻力。报告给出的扭矩精度 ±70 N·m，按本次 6°至11°试验点折算约 0.39%至0.75%；它不是未建模旋转件阻力的上限，但现有资料也没有证据支持把这些余量认定为约 51%功率差异的主因。

### 静态桨距零点已闭合，加载状态尚未闭合

OARF 总距定义为 0.75R 处桨叶总距；NASA 汇编进一步标明它是在零转速下报告。公开弦线扭转多项式在 0.75R 处为 -0.00122°，在多项式舍入精度内就是零，因此把径向扭转锚定到 0.75R 总距没有隐藏数度级固定偏置。[NASA/CR-2017-219486](https://ntrs.nasa.gov/citations/20180000109)

但是，试验报告说明总距来自作动器位置，机构几何误差估计小于约 ±1°；零转速参考报告值到试验转速下实际桨距的受载传递与径向分布没有给出。这仍是关键输入契约未知项。在取得原始标定或受载桨距证据以前，不能用 OARF 反推一个等效偏置并把它当成真实物理参数。

### C81 通用参考弦语义已明确，专用映射未闭合

CAMRAD II 格式说明把 C81 迎角定义在气动系数参考弦上；NASA/TP-2004-212262 公布的四套表在 0°行升力不为零，说明该行不是零升力行。[NASA/TP-2004-212262](https://ntrs.nasa.gov/citations/20040081235) 当前适配器显式求取表内零升力迎角，因此与通用语义相容。但现有资料仍未给出这套 XV-15 表的气动参考弦到几何弦专用偏置，具体映射尚未达到文献级闭合。

原文证据定位沿用 V1 资料审计：TM-86833 的 PDF 第 3 页给出系数定义，第 6 页说明实际旋翼扭矩及轴承扣除，第 7 页说明风修正，第 8 页说明总距测量误差，第 68至69页定义数据字段；CR-2017-219486 的 PDF 第 68 页给出弦线扭转，第 71 页标明零转速总距，第 74 页给出 Run 15 表 A-2；TP-2004-212262 的 PDF 第 34 页开始给出四段 C81 表。

## 现有误差归因证据：必须按等级解释

### MATLAB_RUN

目前可以作为 MATLAB 实跑证据使用的 Codex 工作包括：

- 本页冻结低阶验证配置；
- `run_xv15_prandtl_root_tip_loss_screen` 的经典 Prandtl 根/尖损失筛查；
- `run_xv15_mass_property_single_factor` 的 10°质量属性单点核验。

其中 Prandtl 结果表明经典局部根/尖损失会使高总距 CT/CP 绝对误差略微扩大；它只能排除“局部 Prandtl 损失因子能补回当前载荷缺口”，不能排除非局部有限叶片尾迹。

### EQUATION_REPLICA_PREVIEW

以下历史诊断的证据文件仍明确带 `PREVIEW`，应按方程级复现解释，而不是写成 MATLAB 已验证：

- 实际径向几何交叉检查；
- 完整径向/Mach C81；
- 独立环带动量；
- Eq. (12) 与均匀入流比较；
- delta3；
- 锁定挥舞；
- Mangler 入流；
- 名义旋转增升。

这些结果对“下一步查什么”仍有价值，但如果进入论文的正式定量证据链，应先运行对应 MATLAB runner 并生成非 preview 结果。

## 尚未闭合的关键项与允许的下一步

输入来源方面仍应继续查：

1. Run 15 作动器到 0.75R 实际桨距标定，以及试验转速下的受载桨距传递与径向分布；
2. C81 表的 XV-15 专用参考弦偏置、原始翼型数据、雷诺数、粗糙度和表生成条件；
3. 仅在有同构公开资料时，进一步核对完整旋转组件扭矩余量。

模型形式方面，**非局部尾迹和环带耦合仍是未验证项，不是已证伪项**。因此允许进入下一层诊断，但必须设置严格边界：

- 仍放在 `analysis/` 下作为诊断，不进入 production core；
- 优先做规定螺旋尾迹/升力线/Biot–Savart 非局部诱导，不直接上自由尾迹；
- 尾迹收缩、螺距、涡核等必须来自独立文献或透明理论关系；
- 不允许用 OARF CT/CP/FM 反调尾迹参数；
- 仍以 OARF 作为开发后外部相关性基准，只比较结果；
- 如果非局部尾迹不能改善，也应保留负结果，而不是继续叠加经验增益。

因此，本页不再使用“严格停止扩模”表述。正确边界是：

> **停止无独立物理依据的经验扩模；允许有文献约束、可证伪、与 production core 隔离的模型形式诊断。**

## OARF 数据集的验证角色

由于 OARF Run 15 已用于前期误差诊断，本项目后续应明确区分：

- **OARF Run 15**：开发过程中使用的外部基准/相关性数据；
- **严格独立最终验证集**：如果论文需要“blind external validation”措辞，应另外选取此前未参与模型选择的数据，或事先冻结的数据划分。

这不会否定当前 OARF 比较的数值价值，但会改变它在论文中的证据等级与措辞。

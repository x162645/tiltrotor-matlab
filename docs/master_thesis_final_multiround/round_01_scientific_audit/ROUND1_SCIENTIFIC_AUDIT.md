# 第一轮科学事实与证据终审

## 审查范围

审查覆盖 PR #57 全部论文变更、九/十三状态模型接口、质量与惯量、部件载荷
链、配平与可信度门禁、数值线性化、特征根、短舱时域结果、参数来源、
NASA 图 25 外部旋翼关联、原始参考资料和完整测试入口。正式物理模型和默认
参数均保持只读。

## 主要结论

1. 论文主线“部件级模型—可信配平—十三状态扩展—分层可信度分析”成立，
   但原稿含大量模板化验证叙述，科学信息密度不足。
2. 九/十三状态共同 A 子块并不严格相等。非零项集中于
   `p/r -> p_dot/r_dot`，由逐侧尾流覆盖与平均尾流覆盖的模型定义差异
   引起，分类为 B，不是 D 类代码错误。
3. 三个短舱动态代表点均为可信配平点，时域结果有限且相邻时间步变化低于
   2%；这些证据只支持所选点。
4. 75 deg/40 m/s 是升降舵边界、俯仰力矩、多约束和模型有效域共同问题；
   无约束大舵角诊断不能作为物理需求。
5. 75 deg/60 m/s 在联合优化参数方案下可信，主要体现等效尾翼控制效能
   和有限几何参数对内部配平的作用，不是外部数据调参。
6. NASA 图 25 双流程数字化一致性在声明不确定度内，但旋翼幅值偏差约
   0.063--0.064，平均相对误差约 43%--49%，只能形成初步部件级关联。
7. 执行机构、转子陀螺、机械卡滞和整机外部验证仍存在明确证据缺口。

## 阻塞判定

没有发现使整篇论文物理结论失效的阻塞问题，可以进入结构重写；前提是最终
题目采用“可信度分析”，并落实所有声明降级。未修改任何正式模型或默认
参数。

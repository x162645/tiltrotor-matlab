# 模型与参数边界

## 不得修改

- `model/` 中的正式物理模型函数；
- `params_nominal.m`；
- 九状态、十三状态和输入接口顺序；
- 控制限位、配平可信度门禁和数值默认值；
- 正式默认旋翼路径及 legacy 默认路径；
- 已冻结的纵向参数优化结果；
- 历史配平、导数、特征根和时域数据库。

## 本任务允许修改

- 论文各轮 Markdown 正文；
- 提交级 XeLaTeX 工程；
- 图表布局与论文专用生成脚本；
- 科学审计、证据索引、参数抽查和一致性报告；
- NASA 图线的第二套数字化复核文件；
- 论文所需的只读分析脚本和小型派生数据。

## 参数语义

`REFERENCE` 只表示有明确原始文献来源；`DERIVED` 表示由文献值和明确公式
推导；`DIGITIZED` 表示图线读取；`ASSUMED` 和
`ASSUMED_MODEL_PARAMETER` 是工程假设；`CALIBRATED_EFFECTIVE` 是在本文
内部目标上得到的等效参数；`RESEARCH_PLACEHOLDER` 不具有型号实测含义。

联合优化参数方案不进入正式默认模型，外部旋翼数据未参与该参数优化。论文
不得把“使冻结网格 8/9 点可信”写成型号辨识或外部验证。

## 科学阻塞处理

若发现 D 类代码错误会改变核心物理结论，只记录到第一轮阻塞报告并降低受
影响声明；本任务不静默修复模型。A 类新增物理、B 类模型定义差异、C 类
数值差分和 E 类证据不足分别记录，不混称代码错误。

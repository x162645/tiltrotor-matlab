# NACA 64A223 Geometry Source Audit

Date: 2026-07-02

## Acquired Sources

| Source | Local status | Use in this pass |
|-|-|-|
| NASA TM-X-3069 | Valid PDF, text extracted | Defines the NACA 6/6A coordinate-program route and validation accuracy. |
| NASA TM-4741 | Valid PDF, text extracted | Secondary coordinate-program source. |
| NACA TR-903 | Valid PDF, text extracted | Published 6A-series coordinates for validation sections and the 6A mean-line context. |
| NACA TN-4322 | Local NTRS response is not a valid PDF | Not used. |
| NASA TR R-84 | PDF header valid, pypdf page tree damaged | Not used as a numeric coordinate source in this pass. |

## Findings

- TM-X-3069 describes a program that can generate NACA 6/6A ordinates for arbitrary thickness and camber, but the required 6A airfoil-parameter arrays are stored in the program/subroutine data. They were not reconstructed from the scanned PDF text in this pass.
- TM-X-3069 also warns that ordinates are not linear with thickness-chord-ratio variation, so scaling a published 10 or 15 percent 64A section to 23 percent is not an authoritative 64A223 construction.
- NACA TR-903 provides published tables for sections such as NACA 64A010, 64A210, 64A410 and other 6A examples, but it does not provide a direct NACA 64A223 coordinate table.
- The existing `data/wing_full_angle/airfoils/naca64a223_surrogate.dat` remains a surrogate generated by an explicit approximation, not by the NASA/NACA 6A algorithm.

## Gate Decision

`AIRFOIL_GEOMETRY_GATE=PARTIAL`

No coordinate file in this branch is promoted as a final true NACA 64A223 coordinate set. The surrogate is archived under `data/wing_full_angle/surrogate_v0` and is not eligible for `FULL_WING_MODEL_GATE=PASS`.

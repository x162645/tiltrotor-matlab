## Production Interface

- `wing_full_angle_lookup(alpha,Re,Mach,flapDeg,P)` now performs PCHIP interpolation in alpha and linear interpolation across Re, Mach and supported symmetric plain-flap grids.
- Old `wing_full_angle_lookup(alpha,P)` calls remain supported but report `dimensionReductionActive = true`.
- Out-of-range grid behavior is controlled by `P.wing.fullAngleOutOfRangePolicy`; default is `clamp` and diagnostics expose `outOfRangeClamped`.
- `wing_local_flow` uses local Re and Mach in lookup calls.
- TM-88373 symmetric plain-flap data is not used as differential aileron data.
- The full-angle path is labeled `longitudinal_full_angle_baseline_no_lateral_aileron_aero`; the aileron derivative test is zero by design and `CONTROL_SURFACE_GATE = PARTIAL`.

## Wake Strip Model

- Free-stream and rotor-wake strip portions call the same full-angle coefficient lookup.
- Region differences come only from local velocity, alpha, Reynolds number, Mach number, dynamic pressure, covered area and moment arm.
- No `FNear/FLiftLine` complete-result branch blending is used in the new path.
- Wake coverage uses rotor hub position, rotor axis, disk-wing projection distance, wake radius/contraction, left/right independent wakes and strip overlap area.
- CR-114614 extraction: `data/wing_full_angle/cr114614_wake_formula_extract.csv`.

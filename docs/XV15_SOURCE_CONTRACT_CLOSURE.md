# XV-15 验模输入契约闭合与最小误差核验

## 结论

这次工作没有修改生产模型，没有增加尾迹、损失因子或经验增益，也没有用 OARF 结果反调参数。只完成原始资料追溯，并对已取得独立来源的耦合质量属性包做一个 10°代表点的成对核验。

结论分为四层：

1. **桨叶质量属性虽然与通用假设差别很大，但在 10°代表点没有分辨出性能影响。**报告名义挥舞惯量约为 142.36 kg·m²，一阶质量矩由公开模型分布推得约为 63.09 kg·m；冻结包分别使用 217.74 kg·m²和 85.73 kg·m。成对替换后平均锥度角从 1.2546°变为 1.9425°，但性能系数变化落在数值噪声内。这个单点结果不支持把质量属性视为 10°处数十个百分点误差的主因，也不构成跨工况物理上界。
2. **Run 15 的逐点空气密度已闭合，并可排除为主因。**所用九点为 1.226 至 1.227 kg/m³，与冻结值 1.225 kg/m³只差 0.08%至 0.16%，远小于当前误差。
3. **C81 的通用参考弦语义已经明确，但这套 XV-15 表的具体弦线映射尚未闭合。**C81 的迎角相对气动系数参考弦，而不是相对零升力线；零升力迎角应由表内数据另行确定。当前适配器与这个通用语义强相容，但仍缺该表参考弦到 XV-15 几何弦的专用偏置记录，原始极曲线的雷诺数、粗糙度和转捩条件也未公开。
4. **旋转受载桨距是优先级最高的阻断项之一。**Run 15 的数据字段明确是 0.75R 总距，且来自作动器位置；已知机构几何非线性误差小于约 ±1°。但是从零转速参考报告值到试验转速下实际局部桨距的传递与径向分布仍没有公开测量或可审计标定。这个未知不只限于桨叶弹性，也可能包含变距控制链的受载柔度。

因此，原冻结结论不变：当前通用低阶模型与 XV-15 OARF Run 15 的绝对量级验模不通过。新证据排除了空气密度，在 10°点未发现质量属性的可分辨性能贡献，也证明当前适配器没有把 C81 的零度行直接当作零升力点；但具体参考弦映射尚未闭合，剩余误差仍不能唯一归到某个模型简化上。

## 1. 桨距输入：定义已闭合，受载值未闭合

[NASA/TM-86833](https://ntrs.nasa.gov/citations/19860005773) 的数据字典把 `COLL` 直接定义为 0.75R 处的桨叶总距。报告同时说明，该数值由总距作动器位置得到，控制机构几何非线性造成的误差估计小于约 ±1°。[NASA/CR-2017-219486](https://ntrs.nasa.gov/citations/20180000109) 的汇编图进一步把该总距标为零转速值。

[NASA/CR-114682](https://ntrs.nasa.gov/citations/19740003720) 的 Model 300 设计表也把旋翼控制行程定义在 0.75R；但 [NASA/CR-114626](https://ntrs.nasa.gov/citations/19730016343) 的 1973 年旋翼塔试验使用的是桨尖桨距。两组试验不能混用。该历史报告只能证明当时对变距角和总距位置做过试验前标定，不能替代 1985 年 OARF 的作动器标定。

### 静态 0.75R 换算已经代数闭合

当前验证适配器没有把试验总距直接塞入模型的线性扭转截距，而是使用下面这组完整定义：

| 量 | 冻结定义 |
|---|---|
| 试验输入 | `theta_75,0`：零转速、0.75R 处报告总距 |
| 模型径向坐标 | `x=(r/R-0.0875)/(1-0.0875)` |
| 模型桨距律 | `theta(r)=theta_model+theta_twist*x` |
| 0.75R 坐标 | `x_75=(0.75-0.0875)/(1-0.0875)=0.726027397` |
| 适配公式 | `theta_model=theta_75,0-theta_twist*x_75` |

冻结等效扭转为 `theta_twist=-36.347913°`，所以

\[
\theta_{model}=\theta_{75,0}+26.389581^\circ .
\]

例如，试验 6°点映射为模型输入 32.389581°；把它代回同一桨距律的 0.75R 位置，结果仍严格为 6°。因此 26.389581°只是线性公式在 `0.0875R` 坐标起点处的数学截距，不是给真实桨叶额外增加 26°，也不是实测根部桨距或作动器角。

这只闭合了**静态参考站位和零位换算**，没有把真实非线性径向扭转变成精确线性扭转。实际弦长和非线性扭转的既有诊断已经证明径向几何降阶能解释一部分误差，但不能闭合剩余差距；不能再把它改写成“0.75R 总距定义错了”。

当前本地来源包能直接确认 `0.0875R` 的根部套筒站位。把它进一步称为气动积分的严格根切位置，所依赖的 NASA/CR-2016-219086 表 2 尚未归档到本地来源包。这是来源措辞缺口，不影响上述 0.75R 锚定恒等式；若其物理语义需要修订，影响进入径向形状，而不会制造 0.75R 固定偏置。

### 已知 ±1°误差是否足以解释当前差距

不需要再运行新模型即可作保守检查。冻结结果在 6°至 11°间正好按 1°递增，因此可以把下一个总距点的模型输出当作“有利方向整体增加 1°”的近似上界。对 6°至 10°五个可直接配对的点：

- 推力系数仍低 29.5%至 43.4%；
- 功率系数仍低 40.2%至 47.1%。

这说明报告明确给出的机构几何非线性误差本身不足以造成或闭合当前四至五成差距。这个结论不适用于尚未知的受载桨距传递与径向分布；后者如果形成数度级系统偏移，仍可能显著改变结果，但目前没有证据证明其大小、方向或具体机制。

## 2. C81：通用角度语义明确，专用弦线映射与原始条件未闭合

[NASA/TM-81183](https://ntrs.nasa.gov/citations/19800019796) 的字段定义表明，标准 C81 文件只含升力、阻力和俯仰力矩随迎角与马赫数变化的三张表；雷诺数、粗糙度、转捩和参考弦偏置不属于其字段。[NASA/TP-2004-212262](https://ntrs.nasa.gov/citations/20040081235) 给出的 XV-15 四套表在零马赫数列均有 0°处升力不为零，直接表明这些表的 0°行不是零升力行。

CAMRAD II 的格式说明把迎角定义在气动系数参考弦上，并通过表外偏置连接结构弦。[NASA/CR-152053](https://ntrs.nasa.gov/citations/19780005064) 的 XV-15 资料又明确区分“几何扭转（弦线角）”和“气动扭转（零升力角）”。因此，当前验证适配器从 C81 求零升力迎角、再相对弦线施加修正的做法与通用接口语义强相容；但当前证据没有给出这套 XV-15 表的专用参考弦偏置，不能把具体映射称为文献级闭合。

[NASA/CR-114626](https://ntrs.nasa.gov/citations/19730016343) 将其 1973 年 Model 300 计算所用的早期四段截面数据追溯到联合飞机研究实验室报告 F9305971 和通用动力康维尔分部报告 GDLST 525，并记录了对最大升力及超过最大升力后表值的处理。当前证据尚未建立这两份报告与 1975 年 `CLCD3015` 至 `CLCD3018`、或 TP-2004 最终 C81 表的直接同一性，也没有逐条雷诺数、粗糙度、绊线和转捩条件。TP 公布的最终表值可以复现，原始试验极曲线及其生成链仍不能完整审计。

这项未知可能影响剖面阻力和失速载荷，尤其可能影响功率；但现有证据不足以证明它单独能造成当前误差量级，也不允许以 OARF 结果反推粗糙度或经验增益。

## 3. 桨叶质量属性：参数差异大，10°点性能影响不可分辨

[NASA/CR-114626](https://ntrs.nasa.gov/citations/19730016343) 和 [NASA/CR-2017-219486](https://ntrs.nasa.gov/citations/20180000109) 都直接给出每片挥舞惯量 105 slug·ft²，即 142.3609 kg·m²。

[NASA/TP-2004-212262](https://ntrs.nasa.gov/citations/20040081235) 附录 A 给出 12.5 ft 半径上的 51 点 `MASS` 分布。按公开站位作梯形积分得到：

| 量 | 公开分布推导值 | 证据性质 |
|---|---:|---|
| 等效每片质量 | 60.4735 kg | 分布积分；根部首点含模型化等效项，不称为称重值 |
| 一阶质量矩 | 63.0947 kg·m | 分布积分，可直接对应当前重力挥舞矩输入 |
| 二阶质量矩 | 139.0630 kg·m² | 分布积分，与直接表值相差 2.32% |
| 每片挥舞惯量 | 142.3609 kg·m² | 报告直接列出的名义值，单因素核验采用此值 |

直接列出的惯量与分布积分得到的一阶质量矩并不是同一资料中联合报告的一组直接测量。分布积分所得二阶矩与报告惯量相差 2.32%，支持把它们组成相容的来源质量属性包，但不能证明它们是同一次称量或严格同一分布的实测结果。

冻结通用假设为每片 45 kg 且全展向均匀分布，得到一阶质量矩 85.725 kg·m、挥舞惯量 217.7415 kg·m²。差异虽然分别达到约 35.9%和 53.0%，却不自动意味着推力会产生同量级误差。

在当前代码的纯轴向悬停工况中，平面内速度和周期变距均为零，稳态锥度本身几乎不进入桨叶迎角。当前第一谐波入流仍可通过很小的周期挥舞形成间接耦合，所以不能仅凭方程目测宣称数学上严格为零，必须用成对调用核对。

`analysis/run_xv15_mass_property_single_factor.m` 只在 10°点成对替换整套质量属性，不使用任何 OARF 目标。结果写入 `results/xv15_source_contract_closure/XV15_MASS_PROPERTY_SINGLE_FACTOR.csv`：平均锥度角改变 0.6879°，而推力系数、功率系数和悬停效率记录到的相对变化分别为 −3.28×10⁻⁹%、−2.99×10⁻⁸%和 +2.49×10⁻⁸%。这些微小差值低于求解器可解释精度，只能记为“数值噪声内不可分辨”，不能当作九个数量级的物理上界。

这个核验把 `Ib`、`Sblade` 和等效桨叶质量作为一个耦合包同时替换，不能分别识别 `Ib` 与 `Sblade` 的独立贡献，也不能排除两者在该点相互抵消。它只支持一个窄结论：在当前方程的 10°代表点，质量属性不支持解释该点约 37%的推力系数低估和约 48%的功率系数低估。为遵守最小核验边界，不再扩成多点扫描。

## 4. 逐点密度：已闭合并排除

[NASA/TM-86833](https://ntrs.nasa.gov/citations/19860005773) 的 Run 15 原始明细给出：

- 点 7 至 13：1.227 kg/m³；
- 点 14 至 15：1.226 kg/m³。

冻结值 1.225 kg/m³与这些值只差 0.001 至 0.002 kg/m³。即使直接看有量纲载荷，这也只有 0.08%至 0.16%；推力系数和功率系数又都按同一密度归一化。因此它不可能解释当前约 43%的推力系数误差和约 51%的功率系数误差。

## 5. 扭矩测量边界：已记录修正明确，旋转毂余量仍未知

[NASA/TM-86833](https://ntrs.nasa.gov/citations/19860005773) 说明，扭矩传感器位于齿轮箱下游，电机和齿轮箱损失不进入所比较的旋翼扭矩；传感轴与旋翼之间两个轴承的摩擦扭矩已测量并扣除，轴向载荷交叉项与风也已修正。因此当前约 51%的功率系数误差不是把发动机功率、齿轮箱输入功率或这两个未扣轴承损失误当成旋翼功率造成的。这个结论只覆盖报告明确记录的修正，不代表全部机械余量均已排除。

仍缺的是无桨旋转扣除，以及旋转毂、桨毂、变距连杆和整流罩的气动扭矩预算。试验所称“实际旋翼扭矩”原则上包含传感器下游全部旋转件，而当前代码只积分桨叶剖面载荷。报告给出的扭矩精度是绝对值 ±70 N·m；按 6°至 11°试验点折算约为 0.39%至 0.75%。这个精度不是未建模旋转件阻力的上限，现有资料既不能量化该组件边界差别，也没有证据表明它能达到约 51%。

## 6. 更新后的误差归因

### 已验证会造成明显误差，但只能解释一部分

- 通用截面气动参数与独立 C81 约化参数不匹配；
- 常弦长、线性扭转对真实径向几何的降阶。

### 在已核验点或已知误差范围内不能解释当前量级

- 桨叶质量一阶矩与挥舞惯量：公开来源值与通用假设相差很大，平均锥度也明显变化，但 10°点三个性能系数的变化在数值噪声内不可分辨；这只排除该代表点的当前量级贡献，不外推成全区间物理上界；
- Run 15 逐点空气密度；
- 作动器几何非线性的已知 ±1°范围；
- 功率系数定义，以及报告明确记录的上游齿轮箱边界、两个轴承摩擦扣除和风修正；
- 此前已经运行过的网格、第一谐波入流、独立环带、经典根尖损失、挥舞锁定和名义旋转增升等检查。

### 对验模可信性仍是致命未知，但尚未证明为误差主因

1. 零转速参考报告值到试验转速下实际 0.75R 与径向桨距的传递和变化；
2. 这套 C81 表参考弦到 XV-15 几何弦的专用偏置，以及原始二维极曲线的逐条雷诺数、粗糙度与转捩状态；
3. 试验旋转毂及其他下游旋转件的气动扭矩余量。

第一项同时影响推力和功率，是优先级最高的输入契约；第三项只直接影响功率。所谓“致命”是指在它闭合前不能宣称完成绝对量级验模，不是说已有证据证明它就是当前误差来源。

## 7. 此后的两条路线与单次复算门槛

### 验模路线

保持正式失败结论，不修改生产模型，不再寻找更有利的评分区间。当前模型可以继续用于方程自洽性、控制方向和定性趋势研究，但不能声称已通过 XV-15 绝对载荷验模。

### 误差验证路线

只接受新的独立原始证据：旋转受载桨距或作动器标定、C81 专用参考弦偏置、F9305971/GDLST 525 原始翼型报告、无桨旋转扣除或完整毂扭矩预算。每取得一个能直接映射到现有输入的量，只做一个预先声明的单因素核验。

其中，只有同时满足以下条件，才允许对受载桨距运行**一次**冻结复算：

1. 资料明确对应 OARF Run 15、原始金属桨以及相同转速和构型；
2. 给出数值化的“作动器位置到旋转受载 0.75R 桨距”标定，或者受载径向桨距、扭转分布；同时写明单位、正负号、参考站位、转速、载荷和不确定度；
3. 修正量能够在不查看 `C_T`、`C_P` 和悬停效率结果的情况下，预先且唯一地映射到全部冻结点；只再次给出已知的约 ±1°范围，不开放复算，因为该范围已经用现有相邻点作过有利方向核验；
4. 只建立一个由证据直接给出的输入版本；生产模型、C81、弦长、网格、求解器、九个数据点和 6°至 11°主评分窗口全部保持不变；
5. 不做桨距偏置扫描、参数扫描或 12、24、48、96 网格扫描；
6. 运行前固定报告规则：保留九点和所有物理失败点，同时报告 6°至 11°的逐点误差、平均绝对百分比误差和有符号平均误差。若没有预先独立规定通过阈值，只能称为“修订输入后的外部比较”，不能事后宣布验模通过。

如果这些原始资料不可得，应停止继续分解剩余误差，并把它标为“在现有公开证据和当前模型结构下不可辨识”。这比继续扩充模型或调参更符合本项目“验模而非复现 XV-15”的边界。

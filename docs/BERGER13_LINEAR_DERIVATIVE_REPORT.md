# Berger13 Linear Derivative Report

## Purpose

This workflow is an internal derivative audit for the isolated berger13
13-state / 10-input research model. It is intended to prepare the model for a
future external derivative comparison by first making the current internal A/B
structure explicit and repeatable.

This workflow is not Berger validation, not XV-15 validation, not a
handling-quality conclusion, and not nonlinear response validation.

## Coverage

The report is generated by:

```text
analysis/berger13/report_berger13_linear_derivatives.m
```

It writes small Markdown and CSV artifacts under:

```text
validation/berger13_linear_derivatives/<timestamp>/
```

The representative cases are finite operating points:

| Case | V | betaML | betaMR |
|-|-:|-:|-:|
| `helicopter_like` | 20 m/s | 0 deg | 0 deg |
| `conversion_mid` | 45 m/s | 45 deg | 45 deg |
| `airplane_like` | 100 m/s | 90 deg | 90 deg |
| `asymmetric_nacelle_probe` | 45 m/s | 35 deg | 55 deg |

For each case the report records:

- A13 / B13 dimensions and norms.
- A condition-number diagnostic.
- Scaled condition, SVD, and rank diagnostics described in
  `docs/BERGER13_CONDITIONING_DIAGNOSTICS.md`.
- `betaML` and `betaMR` state-column effects on the first nine rigid-body
  derivatives.
- Angular-acceleration row effects for `betaML` and `betaMR`.
- Nacelle kinematic and damping entries: `A13(10,12)`, `A13(11,13)`,
  `A13(12,12)`, and `A13(13,13)`.
- Norms of all 10 control-input columns.
- Nacelle torque entries `B13(12,9)` and `B13(13,10)`.
- Symmetric legacy opt-in consistency for the first nine derivatives.
- Asymmetric independent rotor-load force/moment delta from the old
  betaMAvg-only result.

## Limitations

- The representative points are finite operating points, not a full trim
  sweep or envelope.
- Conditioning diagnostics are internal numerical health checks, not
  validation or handling-quality pass/fail criteria.
- Non-rotor aero still uses
  `betaMAvg = 0.5*(betaML + betaMR)`.
- Mass properties and inertia still use the betaMAvg approximation.
- The asymmetric probe isolates the current independent rotor-load correction;
  it is not complete asymmetric nacelle aerodynamic validation.
- No Berger 51-state reproduction is claimed.
- No XV-15 or flight-test validation is claimed.
- No handling-quality conclusion is included.
- No nonlinear doublet workflow is included.

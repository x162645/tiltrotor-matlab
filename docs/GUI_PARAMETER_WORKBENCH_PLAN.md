# GUI 参数工作台计划

当前 GUI 参数工作台已经并入综合 GUI 重构。目标是让 139 项可编辑标量
参数通过物理部件和计算模块直接查找、修改、校验和保存。

## 当前界面规则

- 主页面名称为 `参数设置`。
- 参数表列为 `类别、参数、默认值、当前值、单位、状态、来源`。
- 参数筛选只支持类别、关键词和修改状态。
- 单元格编辑只做单项类型和范围检查，并进入待应用状态。
- 点击 `应用修改` 后执行整组参数校验。
- 应用失败时保留用户输入并显示错误状态。
- 应用成功后，配平、线性化和响应结果全部失效。
- 提供恢复选中参数和恢复全部参数。

## 计算边界

本工作台只修改运行时参数结构，不改写 `params_nominal.m`。
不修改 `model/` 和 `analysis/` 中的物理方程、配平算法、线性化算法或
响应算法。

## 验证入口

聚焦测试包括：

- `tests/check_gui_parameter_catalog.m`
- `tests/check_gui_parameter_modified_ids.m`
- `tests/check_gui_parameter_page.m`

完整回归是否运行由当次任务的计算量和停止条件决定。

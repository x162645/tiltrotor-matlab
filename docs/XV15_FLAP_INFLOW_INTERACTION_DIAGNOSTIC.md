# XV-15 悬停第一谐波挥舞—入流耦合诊断

## 目的

本诊断检查当前第一谐波挥舞模型是否是 XV-15 原始金属桨悬停剩余推力低估的主要来源。

为避免把“挥舞本身”和“挥舞对 Eq. (12) 方位入流谐波的响应”混在一起，采用 2×2 交叉实验：

| 方位入流 | 挥舞 |
|---|---|
| Eq. (12) `vi=viMean*(1+cos(psi)*r/R)` | 当前 `beta0+beta1c*cos(psi)+beta1s*sin(psi)` |
| Eq. (12) | 锁定桨叶 `beta=0` |
| 均匀方位入流 `vi=viMean` | 当前第一谐波挥舞 |
| 均匀方位入流 | 锁定桨叶 |

其余全部冻结：NASA 实际径向弦长、NASA 非线性扭转、独立 C81 标量低阶截面参数、OARF 点位转速和全盘平均动量闭合。OARF CT/CP/FM 只用于结果比较，不参与任何参数拟合。

## 关键结构性结果

均匀方位入流时，完整第一谐波挥舞解自动退化为：

```text
beta1c ≈ 0
beta1s ≈ 0
```

例如 10°：

```text
Eq.12:   beta0 ≈ 1.594 deg, beta1c ≈ 0.00036 deg, beta1s ≈ -3.909 deg
Uniform: beta0 ≈ 1.594 deg, beta1c ≈ 0,          beta1s ≈ 0
```

同时，均匀入流下“当前挥舞”和“锁定桨叶”的 CT/CP 在数值精度内相同。这是当前方程结构的直接结果：在纯轴对称悬停中，定常锥度 `beta0` 不进入当前叶素切向/法向相对速度，只有 `betaDot` 会改变 `UP`。

因此：

1. **第一谐波挥舞本身不是剩余悬停 CT 低估的主要来源。**
2. Eq. (12) + 当前挥舞之所以与均匀入流结果几乎相同，是因为 `beta1s` 响应抵消了 Eq. (12) 的 `cos(psi)` 入流谐波。
3. 如果人为锁定桨叶但仍保留 Eq. (12)，这种抵消被移除，CT 略降、CP 明显下降，FM 反而虚高；这不是更好的物理模型，而是一个不一致的“保留谐波入流、禁止相应挥舞响应”组合。
4. 因而不能把 Eq.12+锁定桨叶相对当前模型的差异解释为“真实挥舞损失”。

这与经典旋翼动力学中“谐波入流与谐波挥舞需要耦合处理”的基本认识一致。NASA 的悬停耦合旋翼方程和非均匀入流综述都将谐波入流与桨叶挥舞作为耦合自由度处理，而不是彼此独立关闭。

## 对误差归因链的影响

新增结论：

> **当前第一谐波挥舞不是 XV-15 纯悬停约 28% 剩余 CT 低估的主因；它主要负责响应并抵消当前 Eq. (12) 的方位一阶入流项。**

因此下一步不应继续在 `beta1s`、挥舞惯量或第一谐波增益上调参来补推力。

## 下一候选层

当前剩余误差已经很难由纯空气动力分布修正单独解释。原始 XV-15 金属桨为真实弹性结构，而当前低阶悬停模型使用固定几何扭转，不包含载荷相关的弹性扭转/桨距变形。公开 XV-15 文献明确表明金属桨模型存在重要的 blade torsion mode；但在将其作为悬停 CT 误差源之前，必须进一步找到或推导**悬停载荷下的静态弹性扭转量级**，不能仅凭稳定性文献中“torsion mode 重要”就假定其会补回推力。

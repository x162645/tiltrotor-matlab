## 误差归因

### 1. 截面气动是确定的重要误差来源

M0 改为独立 C81 标量气动后：

- CT MAPE 减少 13.55 个百分点；
- CP MAPE 减少 11.49 个百分点；
- FM MAPE 减少 10.80 个百分点。

因此通用截面气动参数是 M0 系统性低估的重要来源之一。

### 2. 真实径向几何继续带来显著改善

从“C81 标量 + 等效几何”进入 M1-A 后：

- CT MAPE 再减少 8.92 个百分点；
- CP MAPE 再减少 5.88 个百分点；
- FM MAPE 再减少 7.81 个百分点。

相对纯 M0，M1-A 总体改善为：

- CT：减少 22.47 个百分点；
- CP：减少 17.37 个百分点；
- FM：减少 18.61 个百分点。

这支持“常弦长 + 线性扭转”的几何降阶对 XV-15 定量相关性存在中等到显著影响。

### 3. 更完整的二维 C81 并没有继续降低误差

M1-B 比 M1-A 的误差反而增加：

- CT：+3.90 个百分点；
- CP：+5.28 个百分点；
- FM：+3.14 个百分点。

这不能解释为“完整 C81 不正确”。更合理的含义是：在当前其余模型机制仍保持低阶的情况下，标量 C81 约化可能存在一定误差补偿，而恢复更真实的径向/马赫数气动后暴露了其他尚未建模的物理或输入契约问题。

因此不得根据 OARF 结果继续调整 C81 表或人为选择二维气动参数以最小化误差。

### 4. 分环带动量只带来有限改善

M1-C 相对 M1-B：

- CT 改善 2.10 个百分点；
- CP 改善 2.61 个百分点；
- FM 改善 1.56 个百分点。

说明简单径向环带闭合不是剩余 30%–50% CT/CP 偏差的完整解释。

环带动量模型没有非局部叶片间/尾涡耦合，不能用该结果否定规定尾迹、升力线或 Biot-Savart 非局部诱导机制。

## 当前最重要的科学判断

第一阶段已经实际证明：M0 的大误差确实有一部分来自通用截面气动和径向几何降阶，但即使采用更接近 XV-15 的公开几何和完整 C81，CT/CP 仍有明显系统性低估。

因此，下一阶段不应继续通过二维气动参数调节来追求更低 MAPE。优先研究对象应转向：

1. 零转速 0.75R 报告总距到高速旋转受载实际桨距/径向扭转的输入契约；
2. 规定螺旋尾迹、升力线/Biot-Savart 等非局部诱导模型；
3. 在上述机制仍不足时，再研究雷诺数、粗糙度、转捩、压缩性以及旋转部件扭矩边界。

## M1 候选身份说明

目前不能简单因为 M1-A 的 OARF MAPE 最低就把 M1-A 定义为最终 M1。

M1-A 比 M1-B 更准，可能部分来自低阶标量气动对其他缺失物理的补偿。最终 M1 的选择应依据物理来源完整性、独立验证表现和跨工况稳定性，而不是 Run 15 单数据集的最小误差。

第一阶段完成后，WADC 原始金属桨数据继续保留为不同设施外部验证候选，不在本阶段用于模型选择或参数调整。

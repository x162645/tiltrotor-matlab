# GUI 架构与需求

当前 GUI 面向专业分析流程：

```text
参数设置 -> 配平 -> 线性化与模态 -> 操纵响应
```

## 页面

1. `参数设置`
2. `配平`
3. `线性化与模态`
4. `操纵响应`

顶部提供加载项目、保存项目、参数检查、恢复参数、使用说明和工作流状态。

## 参数设置

- 参数目录覆盖 139 项可编辑标量。
- 参数按物理部件和计算模块分类。
- 表格列为 `类别、参数、默认值、当前值、单位、状态、来源`。
- 单元格编辑先进入待应用状态。
- `应用修改` 执行整组参数校验。
- 应用失败时保留输入并标出错误。
- 应用成功后配平、线性化和响应结果失效。

## 计算页面

- 配平页区分飞行工况和配平计算设置。
- 主诊断显示可读中文结论，内部错误码和异常信息保留在技术信息或测试输出中。
- 线性化页显示中文状态量、操纵量、矩阵和模态分类。
- 响应页按波形启停相关输入，并区分扰动量与叠加配平值显示。

## 会话

保存项目使用带 `formatVersion` 的 MAT 文件，包含参数、配平、线性化和响应结果。
加载项目时检查版本和必要字段。不兼容文件必须明确拒绝。

## 边界

GUI 只修改运行时参数结构，不改写 `params_nominal.m`。界面重构不得改变
物理参数数值、模型方程、配平算法、线性化算法或响应算法。

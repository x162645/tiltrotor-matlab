# Parameter Source Inventory

## Scope and counting rules

Static classification correction at commit `ecf97958cd61674e9bf9cbd02e9bfab65d01a8e7`. MATLAB was not run. This document preserves the original 174 inventory IDs and code-use tracing, but separates two questions that were previously mixed:

1. provenance of the current conceptual-model value in this repository; and
2. evidence for a future XV-15 target value, relation, configuration, or conflict.

NASA or other XV-15 references are retained as target-dataset evidence or comparison context. They are not used as proof that the current conceptual value historically came from that source unless explicit project-history evidence exists. No such direct historical proof was established in this correction.

Current-model provenance vocabulary is exactly: `DOCUMENTED_PROJECT_SOURCE`, `DERIVED`, `ASSUMED_CONCEPT`, `NUMERICAL`, `AMBIGUOUS_COUPLED`, `DEPRECATED_UNUSED`, `UNRESOLVED`.

XV-15 target-evidence vocabulary is exactly: `DOCUMENTED_PRIMARY`, `DOCUMENTED_SECONDARY`, `CANDIDATE_PRIMARY`, `REFERENCE_PENDING`, `NOT_APPLICABLE`, `UNRESOLVED`.

XV-15 comparison vocabulary is exactly: `EXACT_MATCH`, `APPROXIMATE_MATCH`, `NUMERIC_CONFLICT`, `CONFIGURATION_DEPENDENT`, `REPRESENTATION_INCOMPATIBLE`, `NO_TARGET_VALUE`, `NOT_APPLICABLE`, `UNRESOLVED`.

Risk labels are split into `current concept-model risk` and `XV-15 reproduction blocker`. A `HIGH` label is a modeling-governance or future-reproduction risk and does not by itself mean a confirmed production-code defect.

Consumer abbreviations: `RB` = `model/rotor_model_bemt.m`; `WG` = `model/wing_model.m`; `FU` = `model/fuselage_model.m`; `HT` = `model/horizontal_tail_model.m`; `VT` = `model/vertical_tail_model.m`; `MP` = `model/mass_properties.m`; `TFM` = `model/total_forces_moments.m`; `EOM` = `model/tiltrotor_eom.m`; `TR` = `analysis/trim_symmetric.m`; `LIN` = `analysis/linearize_numeric.m`.

The current model has uniform quasi-steady induced flow, no dynamic inflow, no nonuniform inflow harmonic, no inter-rotor interference, a one-way scalar rotor-to-wing wake multiplier, simple static tanh stall caps, no airfoil Reynolds/Mach tables, no explicit windmill/autorotation momentum branch, no blade hinge offset/stiffness/damping, and no rotor-speed or control-phasing schedule. `trim_symmetric` closes only `[udot,w?,q?]=0` with theta, common collective and common longitudinal cyclic while conventional surfaces remain zero. Consequently, transition/airplane trim, dense envelopes, and XV-15 fidelity comparisons are blocked even if the current numerical routines return finite values.

# M1 第三阶段来源审计：内段高迎角、旋转失速延迟与尾迹优先级

## 1. 为什么第三阶段不能直接跳到更复杂尾迹

NASA/TM-104023（Felker, 1993）专门以 XV-15、ATB 和 V-22 大尺度悬停数据评价多种倾转旋翼性能方法。研究覆盖升力线、升力面、全势流；不同剖面阻力处理；动量理论、两种规定尾迹和两种自由尾迹。

该报告最关键的结论不是“自由尾迹一定最好”，而是：

- 中等推力系数下，各类方法总体都能给出较好结果；
- 当内段进入高迎角后，预测精度主要取决于对高迎角二维截面升阻特性的处理；
- 将内段升力限制在二维风洞最大升力系数附近的方法，在高推力区明显偏保守；
- EHPIC 允许内段升力系数超过二维最大值，在高推力区得到更好的 XV-15/ATB/V-22 相关性；
- HELIX 对 XV-15 的诱导功率与其他分析总体一致，而不同方法对剖面功率存在明显分歧，因此报告认为剖面功率预测是准确预测倾转旋翼悬停性能的关键之一。

报告还明确说明，没有为了改善相关性而对各分析进行专门调参。

因此，M1-C 中“独立环带入流只改善 2–3 个百分点”之后，不能据此直接认定剩余误差一定来自非局部尾迹。第三阶段必须先确认当前 M1-B/C 是否进入 Felker 所指出的内段高迎角区域。

## 2. 与当前 M1 第一阶段结果的关系

当前同等级 MATLAB 结果是：

- M1-A（真实径向几何 + 标量 C81）CT/CP MAPE = 33.95% / 45.24%；
- M1-B（真实径向几何 + 完整径向 C81）= 37.85% / 50.52%；
- M1-C（M1-B + 分环带动量）= 35.75% / 47.90%。

完整二维 C81 比标量低阶约化反而更差，而改变局部径向入流只追回小部分误差。这与 Felker 1993 指出的机制在方向上相容：更忠实地使用二维高迎角表并不必然更接近旋转桨叶的真实三维内段气动。

但“方向相容”不是机制证据，因此已新增 `analysis/run_m1_stage3_inboard_high_alpha_audit.m`，只记录 M1-B 的局部工况，不改变任何气动模型。

## 3. Felker 1993 对高升力内段的直接证据

Felker 引用 Tung 与 Branum 的模型倾转旋翼试验，报告内段在高推力条件下仍保持附着流：

- 0.125R 处测得升力系数超过 2.7；
- 0.2R 处测得升力系数超过 1.7；
- 两者明显超过相应低雷诺数二维翼型最大升力系数；
- 试验未观察到这些内段位置出现流动分离。

Felker 同时引用 Himmelskamp 的旋转螺旋桨试验和 V-22 三维 Navier–Stokes 工作作为相同现象的支持。报告将其解释为倾转旋翼内段能够在远高于二维失速迎角的状态下维持附着流和较高升力、较低阻力。

这意味着当前 C81 查表法即使数据来源正确，也可能因为其本质是二维截面数据而在高载荷内段失去物理同构性。

## 4. EHPIC 为什么更准，但为什么不能直接照抄

EHPIC 不是通过迎角查表得到升力，而是由涡格 bound circulation 得到截面升力，因此其计算本身没有二维 `CLmax` 硬上限。对超过二维最大升力的状态，其阻力采用一个等效迎角从 C81 表获得。

Felker 明确指出，这种允许升力超过二维最大值的实现最初只是代码开发上的便利选择，开发者本身也把它视为需要改进的限制。因此，M1 不应把“EHPIC 可以超过 CLmax”直接硬编码成任意放大升力的经验规则。

它的价值在于证明一个研究假设：**二维失速约束对高载荷倾转旋翼内段可能过于保守**。

## 5. 可审计的旋转失速延迟模型

NASA/CR-2016-219086（Koning）针对 XV-15 RotCFD 建模时，同样把二维 C81 的旋转失速延迟视为悬停性能的主要气动修正，并采用 Corrigan–Schillings 模型修正 C81。

公开关系以局部 `c/r` 为核心，旋转作用在内段最强，并随半径增加迅速减弱。该工作还展示：

- 只加入失速延迟已经明显改善 XV-15 OARF 悬停相关性；
- CAMRAD II 自由尾迹 + Corrigan 失速延迟在失速后区域仍能保持良好相关性；
- 同时加入失速延迟和尖部损失的 RotCFD 结果优于不加修正的结果。

但 Koning 的实现选择指数 `n=1.8`，并说明较大指数通常相关性更好。因为该工作本身也使用 XV-15 OARF 数据评价模型，所以在本项目的方法学约束下，不能仅因 `n=1.8` 在同一 OARF 数据上表现好就把它作为独立来源的最终参数。

因此第三阶段采取两步门槛：

1. 先做不修改气动的局部工况审计；
2. 只有确认 M1-B 确实进入内段二维失速/峰值升力区，才允许建立来源约束的旋转失速延迟模型，并提前冻结参数选择规则，禁止按 OARF MAPE 选择指数。

## 6. 当前第三阶段局部工况审计

审计程序对每个 6°–11°点、每个径向站记录：

- 平均/最小/最大迎角；
- 局部马赫数；
- C81 平均 CL、CD；
- 在该局部马赫数和径向翼型上的二维 C81 最大 CL 以及对应迎角；
- 当前 CL / 局部二维 CLmax；
- 平均迎角与二维峰值升力迎角之间的裕度；
- 该径向站对总推力、总扭矩的贡献。

内段暂按 `r/R < 0.55` 定义，与现有第一 C81 区域边界一致。审计只回答当前模型是否处于 Felker 机制相关区域，不以 OARF 输出调整任何局部状态。

## 7. 第三阶段决策规则

- 若 6°–11°主要工作桨段明显低于二维峰值迎角，则旋转失速延迟不足以解释当前残差，应优先转向尾迹/诱导或其他输入契约；
- 若高总距点存在大量内段站位处于二维峰值附近或之后，且这些站位对推力/功率有非忽略贡献，则旋转失速延迟成为 M1 下一优先物理；
- 无论结果如何，不允许通过扫描 `n` 或任意升力增益来最小化 OARF 误差；
- 非局部尾迹仍保留为后续候选，但不在局部状态审计完成前被预设为主因。

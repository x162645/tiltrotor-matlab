# 倾转旋翼机正向机理建模：代码、原理与论文公式对应详解

## 一、代码版本与建模主线

本文统一讲解当前的**倾转旋翼机 MATLAB 正向机理模型 v2**。

模型以 Sheng、Zhang、Xiang（2022）关于倾转旋翼机数学建模与稳定性分析的论文为主线，将整机拆分为：

- 左、右旋翼；
- 左、右翼；
- 机身；
- 平尾；
- 左、右垂尾；
- 刚体六自由度运动方程。

论文采用的核心思想是：分别计算各部件气动力和力矩，统一转换到机体系与当前重心，再代入整机六自由度方程，进一步完成配平、数值线性化和稳定性分析。

当前 v2 采用纯 MATLAB 函数实现，没有复刻论文中的 Simulink S-Function 软件结构，但数学信息流与论文中的部件级建模框架一致。

需要特别注意短舱角定义：

\[
\beta_M=0^\circ
\]

代表直升机模式；

\[
\beta_M=90^\circ
\]

代表固定翼模式。

早期基础代码曾采用相反定义，因此两套代码的短舱角不能混用。

## 二、模型总体输入输出

整个模型可统一写成：

\[
\dot{\boldsymbol{x}}
=
f(\boldsymbol{x},\boldsymbol{u},\beta_M,\boldsymbol{P})
\]

其中：

- \(\boldsymbol{x}\)：飞行器状态；
- \(\boldsymbol{u}\)：操纵输入；
- \(\beta_M\)：短舱倾转角；
- \(\boldsymbol{P}\)：质量、惯量、几何、气动和数值参数；
- \(\dot{\boldsymbol{x}}\)：状态导数。

代码调用关系：

```text
run_demo.m
│
├─ params_nominal.m
│
├─ trim_symmetric.m

│       └─ total_forces_moments.m
│           ├─ mass_properties.m
│           ├─ rotor_model_bemt.m       左旋翼
│           ├─ rotor_model_bemt.m       右旋翼
│           ├─ wing_model.m
│           ├─ fuselage_model.m
│           ├─ horizontal_tail_model.m
│           └─ vertical_tail_model.m
│
├─ linearize_numeric.m
└─ stability_report.m
```

完整计算链路：

```text
当前状态、操纵量和短舱角
        ↓
计算重心和惯量变化
        ↓
计算左右旋翼力和力矩
        ↓
计算机翼滑流区和自由流区气动力
        ↓
计算机身、平尾和双垂尾气动力
        ↓
所有力和力矩统一到当前重心
        ↓
代入六自由度刚体运动方程
        ↓
得到状态导数 xdot
```

## 三、坐标系、状态量与控制量

### 3.1 机体系

模型使用航空器常用机体系：

\[
x_B:\text{向前},\qquad
y_B:\text{向右},\qquad
z_B:\text{向下}
\]

所以：

- \(F_x>0\)：向前；
- \(F_y>0\)：向右；
- \(F_z>0\)：向下；
- 向上的升力和旋翼推力通常对应负 \(F_z\)。

右手定则下：

- \(L=M_x>0\)：右滚；
- \(M=M_y>0\)：抬头；
- \(N=M_z>0\)：向右偏航。

### 3.2 状态向量

\[
\boldsymbol{x}
=
[u,v,w,p,q,r,\phi,\theta,\psi]^T
\]

MATLAB 中：

```matlab
x = [u; v; w; p; q; r; phi; theta; psi];
```

| 变量 | 含义 | 单位 |
|---|---|---|
| \(u\) | 机体系前向速度 | m/s |
| \(v\) | 机体系右向速度 | m/s |
| \(w\) | 机体系下向速度 | m/s |
| \(p\) | 滚转角速度 | rad/s |
| \(q\) | 俯仰角速度 | rad/s |
| \(r\) | 偏航角速度 | rad/s |
| \(\phi\) | 滚转角 | rad |
| \(\theta\) | 俯仰角 | rad |
| \(\psi\) | 偏航角 | rad |

当前未加入地面位置 \(X_E,Y_E,Z_E\)，因此是 9 状态模型，适合配平、稳定性和短时响应分析。

### 3.3 控制向量

\[
\boldsymbol{u}
=
[\delta_c,\delta_{cc},\delta_e,\delta_{ec},
\delta_{ail},\delta_{ele},\delta_{rud}]^T
\]

MATLAB 中：

```matlab
uCtrl = [
    collective;
    differentialCollective;
    longitudinalCyclic;
    differentialLongitudinalCyclic;
    aileron;
    elevator;
    rudder
];
```

典型左右旋翼分配：

\[
\theta_{0R}=\delta_c+\delta_{cc}
\]

\[
\theta_{0L}=\delta_c-\delta_{cc}
\]

纵向周期变距：

\[
\theta_{1R}=\delta_e+\delta_{ec}
\]

\[
\theta_{1L}=\delta_e-\delta_{ec}
\]

左右旋翼旋转方向相反，因此周期项和反扭矩符号还必须按旋转方向修正。

## 五、`mass_properties.m`：重心与惯量变化

对应论文式(1)–(3)。

### 5.1 重心变化

\[
\Delta x
=
\frac{m_{\rm NAC}R_H\sin\beta_M}{m}
\]

\[
\Delta z
=
\frac{m_{\rm NAC}R_H(1-\cos\beta_M)}{m}
\]

因此：

\[
\Delta\boldsymbol r_{CG}
=
\begin{bmatrix}
\Delta x\\
0\\
\Delta z
\end{bmatrix}
\]

MATLAB：

```matlab
dx = P.mass.mNac * P.mass.RH * sin(betaM) / P.mass.m;
dz = P.mass.mNac * P.mass.RH * (1-cos(betaM)) / P.mass.m;

cgShift = [dx; 0; dz];
```

所有部件相对当前重心的位置都要更新：

\[
\boldsymbol r_i
=
\boldsymbol r_{i0}
-
\Delta\boldsymbol r_{CG}
\]

这样短舱倾转不仅改变推力方向，也改变各部件力臂。

### 5.2 惯量变化

\[
\boldsymbol I(\beta_M)
=
\boldsymbol I_0
-
\boldsymbol K_I\beta_M
\]

MATLAB：

```matlab
I = P.mass.I0 - betaM * P.mass.KI;
```

当前是低阶线性近似。未来替换 XV-15 数据时，应根据完整部件质量与三维位置，用平行轴定理重新计算惯量矩阵。

## 六、`rotor_model_bemt.m`：旋翼叶素动量模型

对应论文式(4)–(15)。

函数输入包括：

- 机体速度与角速度；
- 短舱角；
- 左右旋翼标志；
- 总距和周期变距；
- 当前重心移动；
- 旋翼参数。

输出包括：

- 旋翼力；
- 重心处旋翼力矩；
- 推力；
- 反扭矩；
- 诱导速度；
- 挥舞或桨盘倾斜量；
- 尾流信息。

### 6.1 旋翼轴方向

推力方向单位向量：

\[
\boldsymbol e_T
=
\begin{bmatrix}
\sin\beta_M\\
0\\
-\cos\beta_M
\end{bmatrix}
\]

直升机模式：

\[
\beta_M=0
\Rightarrow
\boldsymbol e_T=[0,0,-1]^T
\]

固定翼模式：

\[
\beta_M=90^\circ
\Rightarrow
\boldsymbol e_T=[1,0,0]^T
\]

盘内纵向单位向量：

\[
\boldsymbol e_D
=
\begin{bmatrix}
\cos\beta_M\\
0\\
\sin\beta_M
\end{bmatrix}
\]

侧向单位向量：

\[
\boldsymbol e_Y
=
\begin{bmatrix}
0\\1\\0
\end{bmatrix}
\]

### 6.2 轮毂局部速度

轮毂位置：

\[
\boldsymbol r_h
\]

质心速度：

\[
\boldsymbol V_B=[u,v,w]^T
\]

角速度：

\[
\boldsymbol\omega_B=[p,q,r]^T
\]

轮毂局部速度：

\[
\boldsymbol V_h
=
\boldsymbol V_B
+
\boldsymbol\omega_B\times\boldsymbol r_h
\]

MATLAB：

```matlab
Vhub = Vbody + cross(omegaBody, rHub);
```

投影到旋翼局部坐标：

```matlab
Vaxial = dot(Vhub, eT);
Vlong  = dot(Vhub, eD);
Vlat   = dot(Vhub, eY);
```

这对应论文式(5)的坐标变换。

### 6.3 前进比与入流比

\[
\mu
=
\frac{V_{\rm disk}}{\Omega R}
\]

\[
\lambda
=
\frac{V_{\rm axial}+v_i}{\Omega R}
\]

### 6.4 一阶谐波挥舞闭合

论文式(4)：

\[
I_b\ddot\beta
+
I_b\Omega^2\beta
=
M_T-M_{sg}
\]

完整动态挥舞需要桨叶质量分布、挥舞惯量、挥舞铰位置、气动力矩和阻尼等数据。当前代码采用准定常一阶谐波：

\[
\beta(\psi)
=
\beta_0
+
\beta_{1c}\cos\psi
+
\beta_{1s}\sin\psi
\]

当前参数：

```matlab
P.rotor.flapCyclicGain = 1.20;
P.rotor.flapMuGain     = 0.10;
P.rotor.flapLatMuGain  = 0.05;
P.rotor.flapMax        = 18*d2r;
```

并加入与 \(q/\Omega\) 有关的纵向被动挥舞项。

该处理保留了：

```text
周期变距或前飞速度
        ↓
桨盘倾斜
        ↓
推力矢量倾斜
        ↓
产生前向力、侧向力和姿态力矩
```

但没有保留桨叶挥舞瞬态。

### 6.5 径向与方位角离散

径向积分范围：

\[
r_0=0.18R
\]

到：

\[
r=R
\]

MATLAB：

```matlab
rGrid = linspace(rootCut*R, R, nRadial);
```

方位角：

```matlab
psiGrid = linspace(0, 2*pi, nAzimuth+1);
psiGrid(end) = [];
```

整副旋翼载荷近似为：

\[
\text{总载荷}
=
\sum_{\psi}
\sum_r
\text{叶素局部载荷}
\]

### 6.6 局部桨距

\[
\theta(r,\psi)
=
\theta_0
+
\theta_{\rm twist}(r)
+
\theta_{1c}\cos\psi
+
\theta_{1s}\sin\psi
\]

线性扭转：

\[
\theta_{\rm twist}(r)
=
\theta_{\rm tip}
\frac{r-r_0}{R-r_0}
\]

MATLAB 概念形式：

```matlab
twist = twistTip * (r-r0)/(R-r0);

thetaBlade = collective ...
           + twist ...
           + cyclicCos*cos(psi) ...
           + cyclicSin*sin(psi);
```

### 6.7 叶素局部速度

论文式(6)：

\[
U_T
=
\Omega R
\left(
\frac rR+\mu\sin\psi
\right)
\]

即：

\[
U_T
=
\Omega r
+
V_{\rm disk}(\psi)
\]

论文式(7)：

\[
U_P
=
\Omega R
(\lambda_0-\mu\beta\cos\psi)
-v_1-r\dot\beta
\]

当前代码保留：

- 轴向自由来流；
- 平均诱导速度；
- 一阶非均匀入流；
- 挥舞对局部速度的低阶影响。

没有完整保留 \(-r\dot\beta\)，因为模型中没有动态挥舞状态。

### 6.8 非均匀诱导速度

当前使用一阶形式：

\[
v_i(r,\psi)
=
v_{i0}
\left[
1+
\frac rR\cos\psi
\right]
\]

这使旋翼盘前后半盘的诱导速度不同。

### 6.9 叶素迎角

\[
W
=
\sqrt{U_T^2+U_P^2}
\]

\[
\phi_i
=
\operatorname{atan2}(U_P,U_T)
\]

\[
\alpha_b
=
\theta(r,\psi)-\phi_i
\]

MATLAB：

```matlab
W = hypot(UT, UP);
phiInflow = atan2(UP, UT);
alphaBlade = thetaBlade - phiInflow;
```

### 6.10 翼型升阻力系数

\[
C_L
=
C_{L,\max}
\tanh
\left(
\frac{C_{L\alpha}\alpha_b}{C_{L,\max}}
\right)
\]

小迎角时：

\[
C_L\approx C_{L\alpha}\alpha_b
\]

阻力：

\[
C_D
=
C_{D0}
+
k_D C_L^2
\]

MATLAB：

```matlab
CL = CLmax * tanh(liftSlope*alphaBlade/CLmax);
CD = CD0 + kCD*CL^2;
```

### 6.11 叶素升力与阻力

对应论文式(8)–(9)：

\[
dL
=
\frac12\rho W^2 c C_L\,dr
\]

\[
dD
=
\frac12\rho W^2 c C_D\,dr
\]

### 6.12 推力与旋转阻力

对应论文式(10)–(11)：

\[
dT
=
dL\cos\phi_i
-
dD\sin\phi_i
\]

\[
dH
=
dD\cos\phi_i
+
dL\sin\phi_i
\]

叶素扭矩：

\[
dQ=r\,dH
\]

MATLAB：

```matlab
dT = dL*cos(phiInflow) - dD*sin(phiInflow);
dH = dD*cos(phiInflow) + dL*sin(phiInflow);
dQ = r*dH;
```

积分：

\[
T
=
\frac{N_b}{2\pi}
\int_0^{2\pi}
\int_{r_0}^{R}
dT\,dr\,d\psi
\]

\[
Q
=
\frac{N_b}{2\pi}
\int_0^{2\pi}
\int_{r_0}^{R}
dQ\,dr\,d\psi
\]

### 6.13 诱导速度迭代

诱导速度与推力相互耦合：

```text
诱导速度 vi
    ↓
改变叶素迎角
    ↓
改变推力 T
    ↓
推力决定新的诱导速度 vi
```

迭代框架：

```matlab
vi = initialGuess;

for k = 1:maxIter

    T_bemt = blade_loads(..., vi, ...);

    viTarget = momentum_theory(T_bemt, ...);

    viNew = (1-relax)*vi + relax*viTarget;

    if abs(viNew-vi) < tolerance
        break
    end

    vi = viNew;
end
```

松弛更新：

\[
v_i^{(k+1)}
=
(1-\gamma)v_i^{(k)}
+
\gamma v_{i,\mathrm{target}}^{(k)}
\]

悬停动量理论：

\[
T=2\rho A v_i^2
\]

\[
v_i
=
\sqrt{\frac{T}{2\rho A}}
\]

### 6.14 旋翼力与力矩转换

旋翼力：

\[
\boldsymbol F_R
=
T\boldsymbol e_T
+
H_x\boldsymbol e_D
+
H_y\boldsymbol e_Y
\]

反扭矩：

\[
\boldsymbol M_Q
=
s_{\rm rot}Q\boldsymbol e_T
\]

力臂矩：

\[
\boldsymbol M_{\rm arm}
=
\boldsymbol r_h\times\boldsymbol F_R
\]

总旋翼力矩：

\[
\boldsymbol M_R
=
\boldsymbol M_{\rm arm}
+
\boldsymbol M_Q
+
\boldsymbol M_{\rm hub}
\]

## 七、`wing_model.m`：机翼滑流区和自由流区

\[

=
S_{\rm slip}
+

\[

\leq

\leq
S_{\rm slip,max}

### 7.2 滑流区局部速度

\[
\boldsymbol V_{\rm slip}
=
\boldsymbol V_B
+
\boldsymbol\omega_B\times
\boldsymbol r_{\rm slip}

\begin{bmatrix}

### 7.3 当前重心下的机翼气动中心

\[

=
\boldsymbol r_{W0}
-
\Delta\boldsymbol r_{CG}
\]

力臂矩：

\[
\boldsymbol M_{\rm arm}
=
\boldsymbol r_W\times\boldsymbol F_W
\]

## 十二、`tiltrotor_eom.m`：六自由度非线性方程

对应论文式(33)–(36)。

### 12.1 重力分量

\[
\boldsymbol F_g
=
mg
\begin{bmatrix}
-\sin\theta\\
\sin\phi\cos\theta\\
\cos\phi\cos\theta
\end{bmatrix}
\]

水平姿态：

\[
\phi=0,\qquad\theta=0
\]

则：

\[
\boldsymbol F_g
=
[0,0,mg]^T
\]

### 12.2 平动方程

\[
m
\left(
\dot{\boldsymbol V}_B
+
\boldsymbol\omega_B\times
\boldsymbol V_B
\right)
=
\boldsymbol F_{\rm total}
\]

所以：

\[
\dot{\boldsymbol V}_B
=
\frac{\boldsymbol F_{\rm total}}m
-
\boldsymbol\omega_B\times
\boldsymbol V_B
\]

展开：

\[
\dot u
=
\frac{F_x}{m}
-qw+rv
\]

\[
\dot v
=
\frac{F_y}{m}
-ru+pw
\]

\[
\dot w
=
\frac{F_z}{m}
-pv+qu
\]

MATLAB：

```matlab
Vdot = Ftotal/P.mass.m - cross(omegaBody, Vbody);
```

### 12.3 转动方程

\[
\boldsymbol I\dot{\boldsymbol\omega}
+
\boldsymbol\omega\times
(\boldsymbol I\boldsymbol\omega)
=
\boldsymbol M
\]

因此：

\[
\dot{\boldsymbol\omega}
=
\boldsymbol I^{-1}
\left[
\boldsymbol M
-
\boldsymbol\omega\times
(\boldsymbol I\boldsymbol\omega)
\right]
\]

MATLAB：

```matlab
omegaDot = I \ ...
    (Mtotal - cross(omegaBody, I*omegaBody));
```

应使用 `\`，不建议显式写 `inv(I)`。

### 12.4 欧拉角运动学

\[
\begin{bmatrix}
\dot\phi\\
\dot\theta\\
\dot\psi
\end{bmatrix}
=
\begin{bmatrix}
1 & \sin\phi\tan\theta & \cos\phi\tan\theta\\
0 & \cos\phi & -\sin\phi\\
0 & \sin\phi\sec\theta & \cos\phi\sec\theta
\end{bmatrix}
\begin{bmatrix}
p\\q\\r
\end{bmatrix}
\]

MATLAB：

```matlab
T = [
    1, sin(phi)*tan(theta),  cos(phi)*tan(theta);
    0, cos(phi),            -sin(phi);
    0, sin(phi)/cos(theta), cos(phi)/cos(theta)
];

eulerDot = T*omegaBody;
```

最终：

```matlab
xdot = [
    Vdot;
    omegaDot;
    eulerDot
];
```

## 十三、`trim_symmetric.m`：对称配平

对应论文式(37)：

\[
f(\boldsymbol x_e,\boldsymbol u_e)=0
\]

典型对称定常飞行条件：

\[
v=0
\]

\[
p=q=r=0
\]

\[
\phi=0
\]

待求变量可设为：

\[
\boldsymbol z
=

配平残差：

\[

=
\begin{bmatrix}
\dot u\\
\dot w\\
\dot q\\
\gamma_{\rm calc}-\gamma_{\rm target}
\end{bmatrix}
\]

目标函数：

\[
J(\boldsymbol z)
=
\boldsymbol R^T
\boldsymbol W
\boldsymbol R
\]

求：

\[
\boldsymbol z^*
=
\arg\min J(\boldsymbol z)
\]

残差容差：

控制范围：

```matlab
P.control.collectiveLim = [0, 70]*d2r;
```

### 13.1 过渡模式混控

\[

这保证了从直升机模式到固定翼模式的连续过渡，但还不是 XV-15 的真实混控律。

## 十四、`linearize_numeric.m`：数值线性化

对应论文式(38)–(42)。

非线性系统：

\[
\dot{\boldsymbol x}
=
f(\boldsymbol x,\boldsymbol u)
\]

配平点附近：

\[
\Delta\dot{\boldsymbol x}
=
\boldsymbol A\Delta\boldsymbol x
+
\boldsymbol B\Delta\boldsymbol u
\]

其中：

\[
A_{ij}
=
\left.
\frac{\partial f_i}{\partial x_j}
\right|_{\boldsymbol x_e,\boldsymbol u_e}
\]

\[
B_{ij}
=
\left.
\frac{\partial f_i}{\partial u_j}
\right|_{\boldsymbol x_e,\boldsymbol u_e}
\]

### 14.1 A 矩阵中心差分

\[
\boldsymbol A(:,j)
\approx
\frac{
f(\boldsymbol x^+,\boldsymbol u_e)
-
f(\boldsymbol x^-,\boldsymbol u_e)
}{
2h_j
}
\]

MATLAB：

```matlab
for j = 1:nx
    xp = xe;
    xm = xe;

    xp(j) = xp(j) + dx(j);
    xm(j) = xm(j) - dx(j);

    fp = tiltrotor_eom(xp, ue, betaM, P);
    fm = tiltrotor_eom(xm, ue, betaM, P);

    A(:,j) = (fp-fm)/(2*dx(j));
end
```

### 14.2 B 矩阵中心差分

\[
\boldsymbol B(:,j)
\approx
\frac{
f(\boldsymbol x_e,\boldsymbol u^+)
-
f(\boldsymbol x_e,\boldsymbol u^-)
}{
2k_j
}
\]

MATLAB：

```matlab
for j = 1:nu
    up = ue;
    um = ue;

    up(j) = up(j) + du(j);
    um(j) = um(j) - du(j);

    fp = tiltrotor_eom(xe, up, betaM, P);
    fm = tiltrotor_eom(xe, um, betaM, P);

    B(:,j) = (fp-fm)/(2*du(j));
end
```

维数：

\[
A\in\mathbb R^{9\times9}
\]

\[
B\in\mathbb R^{9\times7}
\]

差分步长：

```matlab
P.linear.dx = [
    0.05;
    0.05;
    0.05;
    1e-3;
    1e-3;
    1e-3;
    1e-4;
    1e-4;
    1e-4
];

P.linear.du = 1e-4*ones(7,1);
```

## 十五、`stability_report.m`：特征值分析

线性系统：

\[
\Delta\dot{\boldsymbol x}
=
A\Delta\boldsymbol x
\]

特征值：

\[
\lambda_i=\operatorname{eig}(A)
\]

MATLAB：

```matlab
lambda = eig(A);
```

判断：

- \(\operatorname{Re}(\lambda)<0\)：模态衰减；
- \(\operatorname{Re}(\lambda)>0\)：模态发散；
- 复共轭根：振荡模态；
- 纯实根：非振荡模态；
- 接近零的根：慢模态、中性航向或积分环节。

代码：

```matlab
maxRealPart = max(real(lambda));
openLoopStable = all(real(lambda) < tolerance);
```

## 十七、正向机理建模的含义

模型从：

```text
质量、惯量、几何位置
旋翼半径、转速、弦长、扭转
翼型升阻力关系
机翼、机身和尾翼气动参数
飞行状态、短舱角和操纵输入
```

出发，逐步计算：

```text
叶素局部速度
→ 叶素迎角
→ 叶素升阻力
→ 旋翼推力和扭矩
→ 机翼、机身和尾翼气动力
→ 整机合力和合矩
→ 加速度与角加速度
```

例如总距增大：

\[
\delta_c\uparrow
\]

导致：

\[
\theta_{\rm blade}\uparrow
\]

\[
\alpha_{\rm blade}\uparrow
\]

\[
C_L\uparrow
\]

\[
dL\uparrow
\]

\[
T\uparrow
\]

直升机模式下：

\[
F_z
\]

变得更负，飞机获得更大的向上加速度。

\[
\boxed{

\rightarrow

\rightarrow

\dot{\boldsymbol x}

}

\[

\qquad

}
\]

稳定性：

\[
\boxed{
\lambda=\operatorname{eig}(A)
}
\]

这三条链路构成了倾转旋翼机正向机理建模代码的完整骨架。

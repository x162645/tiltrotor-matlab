# XV-15 径向 C81 截面气动诊断

## 1. 研究问题

PR #68 已将 NASA XV-15 C81 参考气动表约化为当前通用低阶模型能够读取的一组标量参数：

\[
\alpha_{0L},\quad a,\quad C_{L\max},\quad C_{D0},\quad k_D.
\]

本轮继续保持 PR #67 的 XV-15 悬停几何映射、OARF Run 15 工况、诱导速度迭代、NUAA Eq. (12) 入流、第一谐波挥舞和叶素积分不变，只解除一项低阶化：

\[
\text{一组标量截面气动}
\rightarrow
\text{NASA 四个径向 C81 区段 + 局部 Mach 查询}.
\]

因此本轮回答：**把 C81 的径向/Mach 信息压成一组标量，是否是当前外部验模剩余误差的主要来源？**

OARF 的 CT/CP/FM 仍只用于最终比较，不参与 C81 参数识别或表格修改。

## 2. C81 数据与边界

NASA/TP-2004-212262 Appendix A 给出的表头为：

`XV-15 ROTOR AIRFOILS (64X28/18/12/08) (C81 TABLES; INTERPOLATED SPANWISE)`

并给出四个径向边界：

- 0.20--0.55R
- 0.55--0.80R
- 0.80--0.95R
- 0.95--1.00R

本诊断在根切到 0.20R 之间继续采用第一段 C81 数据，不另外构造新的翼型极曲线。局部 Mach 由当前叶素相对速度计算。

C81 是 NASA XV-15 参考分析模型的公开输入，本轮不把它称为原始风洞测量真值。

## 3. 实现方式

新增：

- `analysis/xv15_c81_section_lookup.m`：四段 C81 的迎角/Mach 双线性查询；
- `analysis/xv15_hover_bemt_section_diagnostic.m`：只用于悬停误差归因的 production-BEMT 镜像路径；
- `analysis/run_xv15_spanwise_c81_diagnostic.m`：三方案同工况比较；
- `tests/check_xv15_spanwise_c81_diagnostic.m`：公开表节点与镜像一致性检查。

镜像路径保留 production 的诱导速度更新、Eq. (12) 一阶谐波入流、挥舞残差、叶素推力/扭矩积分和动量闭合。对于 `GENERIC_LOW_ORDER` 和 `SCALAR_C81_LOW_ORDER`，runner 还会与 `rotor_model_bemt_section_aero` 逐点比较，只有镜像一致时才应解释径向 C81 结果。

## 5. 这一层能够得出的结论

### 5.1 对推力 CT

恢复更完整的径向/Mach 截面数据后，CT 并没有向 OARF 试验靠近，MAPE 从 42.87% 变为 48.16%。

因此，**把四段 C81 压成一组标量并不是当前约 40%--50% 推力缺口的主要来源。** 即使给当前 BEMT 更丰富的二维截面升力信息，主要推力缺口仍然存在。

这使下一层应优先检查产生有效迎角和诱导速度的模型形式，而不是继续调五个截面标量。

### 5.2 对功率 CP

结论不同。完整 C81 的高迎角阻力显著提高了计算扭矩，CP MAPE 从 51.12% 降到 27.72%。

因此，**当前二次标量阻力律对功率误差贡献明显。** 特别是在当前线性扭转等效几何下，部分内段叶素达到较高迎角；完整 C81 阻力随迎角明显增加，而 `CD0+kD*CL^2` 的低阶拟合会漏掉其中相当一部分剖面阻力。

这不等价于“完整 C81 已经验模通过”，但说明功率误差与截面阻力低阶化关系比推力误差更强。

### 5.3 对 FM

FM 从标量 C81 的 12.22% MAPE 恶化到 47.94%，不能解释成“更详细的数据更差”。真正原因是：完整 C81 主要修正了 CP，但没有同时修正 CT。

因此标量 C81 阶段较好的 FM 很可能包含**误差抵消**：推力和功率同时偏低，使比值型指标看起来较好。

由此得到一个重要验证原则：

\[
\boxed{\text{不能仅凭 FM 接近试验就判断旋翼模型已得到良好验证。}}
\]

必须同时检查 CT 和 CP 的独立误差。

## 6. 下一层优先级

经过本轮后，剩余问题可以进一步分离：

- CP：截面阻力完整化已经解释了相当一部分误差；
- CT：即使恢复径向/Mach C81 仍明显偏低，因此主矛盾转向**有效入流/三维升力相关的模型形式**。

下一步优先建议做一个严格隔离实验：保持完整 C81、几何、挥舞和动量闭合不变，只比较

\[
v_i(1+\cos\psi\,r/R)
\]

与纯悬停的均匀诱导速度分布。这样可以直接判断当前 Eq. (12) 一阶谐波入流在零前飞速度下是否是推力缺口的重要来源。

叶尖损失会降低局部载荷，在当前 CT 已经明显偏低的情况下，不宜把它作为“补足推力”的第一候选；旋转三维升力/失速延迟则应在入流隔离之后继续检查。

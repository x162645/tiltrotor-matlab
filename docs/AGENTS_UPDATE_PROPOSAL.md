# AGENTS.md 补充建议

请将以下长期规则并入根目录 `AGENTS.md`，保留原有安全与物理约束：

## ChatGPT、GitHub 与 Codex 协作

- `AGENTS.md` 保存长期规则；
- `CODEX_TASK.md` 保存当前分支、任务范围、测试和停止条件；
- GitHub 分支与提交 SHA 作为版本基线；
- Draft PR 保存 diff、审查意见和 MATLAB 验证状态。

Codex 开始任务前必须同时读取 `AGENTS.md` 与 `CODEX_TASK.md`。工作区存在未提交修改时停止并报告。完成后运行相关测试、检查完整 diff、推送到任务分支并报告提交 SHA。未经用户明确授权不得合并 PR。

## 当前长期目标

当前优先保证：

- 概念参数符合基本物理常理和合理数量级；
- 坐标、符号、单位、控制映射、力和力矩合成正确；
- 程序无明确逻辑、尺寸和数值稳健性错误；
- 配平和线性化结果可回代、可检查；
- 为以后替换 XV-15 或其他型号数据保留接口。

精确 XV-15 参数不构成当前代码修改前提。不得仅因概念参数与 XV-15 不同而替换参数。

## 运行时长控制

在速度精扫、正反扫、大量多初值、逐点 Jacobian、Monte Carlo 或高密度参数扫描前，先估算工况数量、模型调用次数、内部迭代次数和运行时间。

默认采用：

```text
单一代表工况快速检查 → 局部针对性检查 → 必要时扩大范围
```

预计运行超过数分钟时先报告并等待确认。

## 参数与测试原则

- `ASSUMED` 概念参数可以继续使用，前提是数量级合理、语义明确、代码自洽；
- 不得将概念参数描述为型号实测值；
- 不得为了通过测试调整质量、惯量、几何或气动参数；
- 不得隐藏异常、未收敛、NaN、Inf 或复数；
- 测试通过只证明覆盖工况下的内部一致性，不代表型号验证。

# M2 双向短舱机械耦合：来源与方程合同

## 1. 目的与模型身份

本文档只定义未来 M2 的机械学边界，不修改 frozen M0、frozen M1，也不改变现有 D13 代码。

现有 D13 已实现：

- 左/右短舱角与角速度状态；
- 二阶短舱指令执行机构；
- 执行机构反作用力矩；
- 随短舱角变化的移动点质量 CG / 惯量重构；
- 短舱倾转速率引起的旋翼陀螺力矩。

其正式边界仍为：

`PRESCRIBED_NACELLE_MOTION_TO_RIGID_BODY_ONE_WAY`

因此 M2 的新增研究问题不是“加入短舱角状态”，而是：

> 如何在保持低阶飞行动力学范围的前提下，把机身—短舱/旋翼之间的惯性耦合和铰链广义载荷变成双向动力学闭合，而不是规定运动的单向扰动输入。

## 2. 主要来源

### 2.1 Su et al. (2019)

Jianmin Su, Chengyue Su, Sheng Xu, Xiaoxing Yang,
`A Multibody Model of Tilt-Rotor Aircraft Based on Kane's Method`,
International Journal of Aerospace Engineering, 2019,
DOI: `10.1155/2019/9396352`.

来源角色：`PRIMARY_MULTIBODY_FORMULATION_REFERENCE`。

公开全文明确指出：

- 短舱/旋翼质量相对整机不可忽略；
- 倾转运动会改变 CG 与惯量并引起机身—短舱相互作用；
- 采用 `u,v,w,p,q,r,omega` 七个广义速率，其中 `omega` 为短舱相对机身倾转角速度；
- 分别构造机身与短舱/旋翼的广义主动力和广义惯性力；
- 基于 Kane 方程得到广义速率的一阶微分方程；
- 论文同时比较单体与多体 XV-15 纵向配平，并研究短舱倾角指令跟踪时的扰动力矩。

本项目不直接复制其全部模型参数或气动模型；该文献用于确定“短舱相对运动必须作为独立多体自由度进入惯性力/广义力闭合”的方法学依据。

### 2.2 Li, Qu & Wang (2010)

Haixu Li, Xiangju Qu, Weijun Wang,
`Multi-body Motion Modeling and Simulation for Tilt Rotor Aircraft`,
Chinese Journal of Aeronautics, 23(4), 415--422, 2010,
DOI: `10.1016/S1000-9361(09)60236-3`.

来源角色：`INDEPENDENT_MULTIBODY_CROSSCHECK`。

公开全文/摘要明确把机体、短舱和旋翼视为独立实体，利用 Newton 定律和角动量定理对各质量单元积分得到多体运动方程，并指出普通 6-DOF 单刚体方程不能包含转换阶段的惯性耦合效应。该文献还明确把 CG 变化和高速旋翼倾转产生的陀螺力矩列为转换阶段的重要动力学因素。

它与 Su 2019 的数学工具不同（Newton/角动量积分 vs Kane），但对“需要多体惯性耦合而非只改变总惯量参数”的物理判断一致。

## 3. M2 的建模选择

### 3.1 不采用“在 D13 上孤立补一个 I_dot * omega”作为最终方法

现有 D13 把移动短舱质量重新汇总成瞬时整机 CG 与瞬时惯量，再代入标准刚体角动量方程。

如果只在这一路径上机械增加：

`I_dot * omega_body`

同时又单独加入短舱相对角动量、移动质量加速度或铰链反力，存在重复计入或漏计惯性项的风险。

因此 M2 正式实现前必须以“分体运动学 -> 各体惯性力/惯性矩 -> 广义方程”统一推导。`I_dot*omega` 可以作为最终方程展开后的可识别项和单项审计量，但不应作为未经统一推导的独立补丁。

### 3.2 推荐最低阶广义坐标/速率

保持刚体姿态和左右独立短舱自由度：

- 机体平动速度：`u,v,w`；
- 机体角速度：`p,q,r`；
- 左短舱角/相对角速率：`beta_L, omega_L`；
- 右短舱角/相对角速率：`beta_R, omega_R`；
- 姿态仍用现有 Euler 角作为运动学状态。

左右短舱独立是为了保留差动倾转及横侧向耦合能力；对称转换可作为 `beta_L = beta_R` 的不变流形/退化检查，而不是从模型结构中删除左右自由度。

## 4. 最低阶运动学合同

以机体固定参考点 `O_B` 为基准，对第 i 个短舱/旋翼等效刚体：

`r_i = r_i(beta_i)`

其相对机体的速度必须显式包含：

`rDot_i = (dr_i/dbeta_i) * betaDot_i`

绝对速度形式必须包含：

`v_i = v_OB + omega_B x r_i + rDot_i`

绝对加速度展开时至少包含：

- 机体参考点平动加速度；
- `alpha_B x r_i`；
- `omega_B x (omega_B x r_i)`；
- `2 omega_B x rDot_i`（Coriolis 型交叉项）；
- `rDDot_i`，其中包含 `betaDDot_i` 与几何二阶项。

短舱角速度必须写成机体角速度与相对倾转角速度的合成；旋翼高速自转角动量在此基础上继续保留现有倾转速率陀螺贡献。

## 5. 双向广义力合同

未来 M2 的短舱方程不能只有：

`betaDDot = actuator_command_model(beta_cmd, beta, betaDot)`

而应闭合成广义铰链方向的力矩平衡，至少区分：

- 执行机构输出力矩 `Q_act`；
- 重力关于倾转铰的广义力矩 `Q_g`；
- 旋翼气动力/气动力矩关于倾转自由度的广义贡献 `Q_aero`；
- 高速旋翼角动量与机体/短舱运动产生的陀螺广义贡献；
- 机身运动引起的惯性耦合广义力矩 `Q_inertial_coupling`；
- 若有可靠来源，再加入摩擦、阻尼、传动柔性或限位载荷。

最小形式应满足：

`Q_act + Q_external - Q_inertial = 0`

其中 `Q_inertial` 必须由统一的多体运动学推导，而不是由试验曲线反拟合的经验铰链力矩。

机身方程同时必须受到短舱/旋翼对机身的反作用，因此短舱载荷与机体响应是双向闭合，而不是单向添加扰动力矩。

## 6. 参数来源分类

M2 需要新增的每个机械参数必须标记：

- `REFERENCE`：明确文献值；
- `DERIVED`：由几何、质量和明确公式推导；
- `ASSUMED`：只允许概念模型/灵敏度，不得称 XV-15 数据；
- `UNKNOWN`：保留缺失，不可通过 OARF/WADC/动态响应反求后冒充物理参数。

特别是：

- 短舱/发动机/旋翼组合质量；
- 相对倾转轴的局部惯量张量；
- 倾转铰位置；
- 执行机构等效转动惯量；
- 执行机构刚度/阻尼/带宽；
- 传动柔性与摩擦；

不得用“使 XV-15 转换响应更像试验”作为参数来源。

## 7. M2 实现前的必做单元验证

### 7.1 固定短舱退化

当：

`betaDot_L = betaDot_R = 0`

且短舱角固定时，新增相对运动惯性项应消失，M2 应退化到对应固定构型刚体模型（允许仅有模型身份明确的静态 CG/惯量差异）。

### 7.2 零短舱质量退化

令短舱/旋翼移动体质量和相对惯量趋近 0 时，多体附加惯性耦合必须趋近 0。

### 7.3 左右对称不变流形

对称初值、对称气动和相同左右短舱指令下，左右短舱状态应保持一致，不能由数值实现凭空产生差动状态。

### 7.4 内力反作用检查

只施加内部短舱执行机构力矩、关闭外部气动和重力后的隔离系统中，应验证执行机构对短舱和机身的作用/反作用一致，不能创造净外部角动量。

### 7.5 坐标与功率一致性

铰链广义力矩和 `betaDot` 的乘积应与执行机构机械功率符号一致；左右短舱坐标、倾转正方向及机体俯仰力矩符号必须逐项测试。

### 7.6 D13 回归

M2 应提供关闭双向附加耦合后的 D13-compatibility 模式，用于确认新增代码没有无意改变既有单向模型结果。该兼容模式只是软件回归，不是物理验证。

## 8. 外部验证边界

现有公开 XV-15 动态资料仍未闭合同一 flight/run 的 HIGH-homology 输入合同，因此：

- M2 可以进行方程、守恒、退化、数值和文献模型层级验证；
- 可以利用 XV-15 稳态/组件层证据约束静态与准稳态结果；
- 可以比较公开多体文献中的定性/可数字化趋势，前提是明确证据角色；
- 不得把 generic XV-15 mass/inertia/actuator 参数拼接后称作 exact XV-15 nacelle dynamic validation。

若未来没有 HIGH-homology 动态记录，论文应把 M2 的动态证据声明限制为：

`SOURCE_CONSTRAINED_MULTIBODY_MODEL + INTERNAL/DEGENERACY VERIFICATION + LIMITED EXTERNAL TREND COMPARISON`

而不是“XV-15 动态验证完成”。

## 9. M2 当前冻结前置条件

在真正修改 `model/` 前必须完成：

1. Stage 10 Sheng comparison-definition isolation 的实际 MATLAB 结果；
2. 明确 M2 采用 Kane 广义方程还是等价、逐项可审计的 Newton-Euler 分体推导；
3. 建立左右短舱几何/质量/局部惯量参数来源表；
4. 预先定义最小单元测试和退化测试；
5. 创建独立 M2 model identity，禁止覆盖 frozen M1。

只有这些合同闭合后，才进入 M2 代码实现。

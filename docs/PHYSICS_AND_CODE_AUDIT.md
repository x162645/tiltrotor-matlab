# 物理合理性与程序正确性审计

## 1. 审计目标

本审计面向当前概念型倾转旋翼机模型，目标是：

1. 判断名义参数是否符合基本物理常理和数量级；
2. 检查坐标、单位、作用点、力矩、控制映射和数值算法是否自洽；
3. 识别会导致错误结果、虚假收敛、非连续或数值异常的程序问题；
4. 为未来替换 XV-15 或其他型号数据保留清晰接口。

精确 XV-15 参数不是本阶段修改代码的前置条件。公开型号数据只用于数量级交叉核查和后续接口设计。

## 2. 当前名义参数的基本数量级

基于 `params_nominal.m`：

- 总质量：6000 kg；
- 单个旋翼半径：3.8 m；
- 叶片数：3；
- 名义弦长：0.38 m；
- 转速：62 rad/s；
- 左右旋翼中心横向位置：约 ±5 m；
- 名义惯量主对角项：18000、30000、45000 kg·m²。

由这些参数得到：

- 旋翼尖速约 235.6 m/s；
- 旋翼实度约 0.0955；
- 单旋翼盘面积约 45.36 m²；
- 双旋翼总盘载约 648.5 N/m²；
- 以每副旋翼承担一半重量估算的悬停诱导速度约 16.27 m/s；
- 三个名义回转半径约为 1.73、2.24、2.74 m；
- 若 `mNac=900 kg` 表示左右移动短舱总质量，`RH=0.75 m`，90° 倾转时重心在 x、z 方向各移动约 0.1125 m，合位移约 0.159 m。

以上数量级适合作为概念型倾转旋翼机初始参数，没有发现需要仅因“不同于 XV-15”而立即替换的项目。

## 3. 参数语义约定

为保证当前公式自洽，建议采用以下明确语义：

- `P.mass.m`：整机总质量；
- `P.mass.mNac`：左右两套参与倾转的移动部件总质量；
- `P.mass.RH`：移动质量等效质心到倾转轴的距离；
- `P.mass.I0`：`betaM=0` 时的概念名义惯量矩阵；
- `P.mass.KI`：低阶惯量随倾转角变化的概念系数；
- `P.control.*Lim`：当前模型的允许输入包络；在得到真实机械限制前，不应标注为型号实际限位。

## 4. 已确认的程序问题

### 4.1 副翼限幅未实际应用

`params_nominal.m` 定义了 `P.control.aileronLim`，但 `total_forces_moments.m` 将原始 `uCtrl` 直接传入 `wing_model.m`。升降舵和方向舵已经限幅，副翼通道遗漏。

影响：

- 超范围副翼输入仍会继续放大机翼载荷；
- 三个常规舵面通道的限幅行为不一致；
- 线性化或异常输入测试可能得到不符合模型约定的结果。

处理：在合力合矩入口生成实际施加控制量，对副翼、升降舵、方向舵统一限幅，并把实际施加值写入诊断输出。

### 4.2 欧拉角奇异区保护不完整

`tiltrotor_eom.m` 对 `cos(theta)` 设置了下限，但第一行仍直接调用 `tan(theta)`。在 `theta` 接近 ±90° 时，第一行和第三行使用了不同的分母保护逻辑。

影响：

- 奇异区附近仍可能出现极大值或不一致的欧拉角速度；
- 当前保护不能完整实现其设计目的。

处理：统一使用受保护的 `sin(theta)/cosThetaSafe`。

### 4.3 数值线性化缺少差分步长有效性检查

`linearize_numeric.m` 检查了差分向量尺寸，但未检查步长是否为正、有限、实数；`report.finite` 也未排除复数矩阵。

影响：

- 零或非法差分步长可能产生除零或无意义导数；
- 有限复数结果可能被误标为有效。

处理：增加正值、有限值、实数检查，并让 `report.finite` 同时覆盖 `A`、`B` 和基点导数。

## 5. 当前可接受的概念化处理

以下项目是模型精度限制，不作为本轮阻断问题：

- `I = I0 - betaM*KI` 的低阶惯量规律；
- 标量线性桨叶扭转；
- 均匀诱导速度；
- 低阶机身和尾翼气动系数；
- 机翼近法向流与升力线分支的平滑混合；
- 暂未建立真实转速调度和真实机械操纵限位；
- 暂未建立完整径向弦长、扭转和翼型数据库。

这些项目需要保留清晰接口，并在使用范围和结论中注明适用性。

## 6. 后续接口方向

未来升级可逐步增加：

```matlab
P.mass.components
P.mass.inertiaModel
P.rotor.radialStations
P.rotor.chordDistribution
P.rotor.twistDistribution
P.rotor.airfoilDatabase
P.rotor.omegaSchedule
P.control.physicalLimits
P.control.modelLimits
P.trim.searchBounds
```

接口升级应保持现有标量参数可作为默认回退值，避免一次性破坏当前可运行模型。

## 7. 本轮验证边界

本轮优先执行轻量、确定性的检查：

- 参数有限性和数量级；
- 惯量对称性和正定性；
- 几何位置关系；
- 控制限幅一致性；
- 左右对称性；
- 线性化差分输入合法性；
- 现有内部测试。

暂不执行大范围速度精扫、正反扫、多参数 Monte Carlo 或逐点 Jacobian 扫描。

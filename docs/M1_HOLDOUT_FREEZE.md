# M1 跨设施外部验证冻结记录

## 1. 冻结目的

本记录在读取或执行 WADC 原始金属桨外部验证数值之前建立。

项目主线固定为：研究通用低阶倾转旋翼飞行动力学/旋翼气动模型在公开 XV-15 数据上的分层外部验证、模型形式诊断与可信适用域，而不是通过拟合把模型改造成 XV-15 数字孪生。

因此，在进入不同设施 WADC 数据前必须先冻结用于外部验证的 M1 主模型身份。WADC 输出不得用于选择 M1 阶段、调整气动参数、调整总距、调整诱导速度、调整尾迹参数或改变报告窗口。

## 3. 冻结的 M1 主模型身份

外部验证主模型固定命名为：

`M1_HOLDOUT_V1 = M1_E1_GENERIC_CORRIGAN_N1`

其物理内容固定为：

1. XV-15 原始金属桨公开真实径向弦长分布；
2. XV-15 原始金属桨公开非线性扭转分布，并以 0.75R 总距定义完成输入映射；
3. 四个径向区域的公开 C81 气动表，按局部马赫数和迎角查表；
4. 通用 Corrigan-Schillings 一阶旋转失速延迟，指数固定为 `n=1`；
5. 全盘标量动量诱导速度闭合，并保留既有 M1-E-1 的一阶方位入流形状 `viField = vi*(1 + cos(psi)*(r/R))`；
6. 当前低阶一阶谐波挥舞求解；
7. 不加入经验 CT/CP 增益；
8. 不加入固定总距偏置；
9. 不加入 OARF 反求参数。

冻结实现对应 `analysis/run_m1_stage3_corrigan_stall_delay.m` 中 `CORRIGAN_GENERIC_N1` 分支。**冻结模型身份以该实现分支为准。**

### 3.1 冻结后文字审计更正

首次冻结记录将第 5 项简写为“全盘均匀动量诱导速度闭合”。在 WADC 数值已经可见后进行代码-文档一致性审计时发现，该表述遗漏了 M1-E-1 实现中一直存在的一阶方位入流形状。当前修订仅把文档改为与冻结前已存在的实现完全一致；没有修改 MATLAB 方程、参数、Corrigan 指数、入流公式或任何 WADC 计算结果。首次冻结提交 `d313296a...` 保留，可审计证明模型实现是在查看 WADC 数值之前冻结的。

## 4. 为什么不选择误差最低的其他阶段

本冻结不是按 Run 15 MAPE 排名选模型。

- M1-A 的标量 C81 在 Run 15 上 FM 更小，但完整径向 C81 的 M1-B 暴露出误差抵消风险，因此不能因为数值更好就优先选择信息更少的标量气动作为最终物理模型。
- M1-E-2 使用文献中针对 XV-15/OARF 相关性采用的 `n=1.8`，其证据角色明确为 `NONINDEPENDENT_XV15_OARF_CORRELATED_VARIANT`，不得作为独立验证主模型。
- M1-F 非局部 Landgrebe/Biot-Savart 诊断在 7°-11°显示 CT/CP 数个百分点改善，但 6°出现病态诱导分布/非物理功率行为；当前内段尾迹几何属于假设推广，因此 M1-F 不能晋升为完整固定窗口的主模型。
- M1-D 受载扭转方向为减小有效桨距并恶化相关性，不支持把未知正桨距偏置并入主模型。

因此 `M1_HOLDOUT_V1` 选择的是：来源角色可审计、在固定 6°-11°窗口内全部得到物理解、未使用当前 OARF 输出选择参数，并保留足够低阶结构的 M1-E-1。

## 5. 冻结前已知开发性相关结果

OARF Run 15 仅为开发性外部相关性，不是后续 holdout：

- CT MAPE：约 32.73%；
- CP MAPE：约 45.89%；
- FM MAPE：约 7.59%。

这些数值只记录冻结前模型状态，不构成 WADC 模型选择准则。

## 6. M1-F 的研究结论保留方式

M1-F 不删除，也不视为失败代码。它保留为模型形式诊断证据：

- 非局部尾迹对高载荷子区间 CT/CP 有可辨识影响；
- 当前经典 Landgrebe 高扭转适用性和内段尾迹推广不足以支撑完整 6°-11°模型身份；
- 后续若研究更高阶自由尾迹，应建立 M2 或新的明确模型身份，不能在看到 WADC 后回改 `M1_HOLDOUT_V1`。

## 7. WADC 外部验证停止规则

一旦开始读取 WADC 数值：

- 禁止修改 `M1_HOLDOUT_V1` 的 Corrigan 指数；
- 禁止修改 C81、几何或总距定义以降低 WADC 误差；
- 禁止增加 CT/CP/FM 经验倍率；
- 禁止以 WADC 误差选择诱导速度模型；
- 禁止删除失败点；
- 禁止事后改变预声明验证窗口；
- 禁止将 WADC 数据重新标为模型开发数据后继续调参，再把同一数据称为验证；
- 所有不支持点、数值失败和大误差必须保留。

若 WADC 显示 `M1_HOLDOUT_V1` 改善不能泛化，这一结果本身就是研究结论，应据此收缩可信适用域，而不是修改冻结模型。

## 8. 外部验证目标

WADC 只回答：

> 在不再修改模型的条件下，M1 相对 M0 在另一设施、另一试验系列和不同转速/马赫范围中，是否仍保持可解释的定量改善，以及改善发生在哪些载荷区域。

这一步是本项目从“模型开发性相关”转入“post-freeze 跨设施外部验证”的关键门槛。

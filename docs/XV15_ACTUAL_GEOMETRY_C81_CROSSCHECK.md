# XV-15 原始金属桨：真实径向几何 × 完整 C81 交叉诊断

## 目的

前序诊断分别检查过：

- 低阶等效几何 + 完整四段 C81 / 局部 Mach；
- NASA 原始金属桨径向 chord / 非线性 twist + 标量化 C81；
- 实际径向几何 + 独立环带动量。

这些单因素结果不能排除“几何降阶误差与截面气动降阶误差存在显著交叉项”。因此本诊断同时恢复：

1. NASA 原始金属桨公开径向 chord 分布；
2. NASA 原始金属桨非线性 twist polynomial；
3. NASA/TP-2004-212262 Appendix A 四段 C81 参考气动表；
4. 各叶素局部 Mach；

并保持当前第一谐波挥舞、Eq. (12) 方位入流和动量闭合逻辑不变。

OARF Run 15 的 CT/CP/FM 只用于外部比较，不参与 C81、几何、入流或闭合参数拟合。

## 比较方案

- `ACTUAL_GEOM + SCALAR_C81 + GLOBAL`：真实径向几何 + C81 的标量低阶约化 + 一个全盘平均诱导速度；
- `ACTUAL_GEOM + FULL_C81 + GLOBAL`：真实径向几何 + 四段 C81 + 局部 Mach + 一个全盘平均诱导速度；
- `ACTUAL_GEOM + FULL_C81 + ANNULAR`：上一方案基础上，把全盘平均动量闭合换成独立径向环带闭合。

第三种方案仍然只是局部 annular momentum 诊断，不等价于有限叶片 prescribed/free wake，也不包含环带之间的 Biot-Savart 尾迹耦合。

### 9°–11° 高总距共同区间

| 方案 | CT MAPE | CP MAPE | FM MAPE |
|---|---:|---:|---:|
| 实际几何 + 标量 C81 + GLOBAL | 28.684% | 41.062% | 2.312% |
| 实际几何 + 完整 C81 + GLOBAL | **31.431%** | **46.598%** | **6.293%** |
| 实际几何 + 完整 C81 + ANNULAR | **31.084%** | **45.370%** | **4.709%** |

完整 C81 并没有在真实径向几何上继续修复推力/功率低估，反而使 CT、CP 误差增大。独立环带闭合只能追回很小一部分。

### 10° 代表点

OARF：

- `CT = 0.013089`
- `CP = 0.001358`
- `FM = 0.7797`

计算：

| 方案 | CT | CP | FM |
|---|---:|---:|---:|
| 实际几何 + 标量 C81 + GLOBAL | 0.00930993 | 0.000799518 | 0.794468 |
| 实际几何 + 完整 C81 + GLOBAL | **0.00894463** | **0.000722979** | **0.827376** |
| 实际几何 + 完整 C81 + ANNULAR | **0.00898146** | **0.000738641** | **0.814839** |

因此，恢复更完整的二维截面气动后，模型并未朝 OARF 推力与功率方向收敛；FM 反而偏高，表现为模型同时低估推力和功率，但功率下降相对更明显。

## 误差归因含义

这一交叉项使以下解释进一步失去作为“主要剩余误差源”的支持：

- 面积等效 chord / 线性 twist 单独造成全部剩余误差；
- 把四段径向/Mach C81 压成一组标量单独造成全部剩余误差；
- 一个全盘平均诱导速度只要换成独立 annuli 就足以恢复试验性能。

更准确的表述是：

1. 几何降阶具有中等贡献；
2. generic 截面参数具有明显贡献；
3. 但在真实几何上恢复完整二维 C81 后，仍保留约 31% 的高总距 CT MAPE；
4. 独立环带动量只能把该值从约 31.43% 改善到约 31.08%；
5. 因此剩余误差越来越难用“二维输入参数没有取真实”来解释。

## 下一层

下一步应检查有限叶片三维诱导/尾迹机制，而不是继续对 C81 或 collective 做 OARF 反调。建议仍按由低到高的顺序：

1. 先做有明确理论符号的有限叶片 tip/root loss 量级筛查；
2. 若其方向和量级不足，再进入 prescribed helical wake / lifting-line / Biot-Savart 耦合；
3. 只有在三维气动层仍无法解释残差时，再重新提高结构弹性模型优先级。

# XV-15 旋转三维升力增强诊断

## 1. 研究问题

前序悬停验模已经逐层排除或限定了以下误差来源：

1. 数值离散不是当前主因；
2. 弦长/扭转的标量等效不是主要 CT 误差源；
3. generic 截面参数确实贡献了一部分误差，但不能解释全部缺口；
4. C81 径向/Mach 信息压成一组低阶参数不是主要剩余 CT/CP 误差源；
5. 纯悬停下 Eq. (12) 一阶方位入流与第一谐波挥舞几乎结构性抵消，因此也不是主要 CT 误差源。

本轮继续问：

> 当前二维叶素气动没有显式表达的旋转三维升力增强 / 失速延迟，能否解释剩余的大幅 CT 低估？

## 2. 为什么本轮先做“量级筛查”而不是直接选一个复杂经验模型

旋转增升/失速延迟模型之间的形式和经验系数差异较大。Corrigan--Schillings 模型具有直升机/螺旋桨经验根源，但需要局部失速角、零升力角和极曲线平移等额外定义；如果在当前阶段直接把这些量按 OARF 结果反推，就会把新的标定自由度混入外部验模。

因此本轮先采用更透明的 Snel 型一阶修正做“物理量级筛查”：

\[
C_{L,3D}
=
C_{L,2D}
+g\,3.1\left(\frac{c}{r}\right)^2
\left(C_{L,pot}-C_{L,2D}\right).
\]

其中：

- \(g=1\) 对应名义 Snel 修正强度；
- \(g\neq1\) 只用于敏感性包络，不称为物理标定参数；
- 本轮不修正阻力，保留原二维低阶阻力律，以单独观察升力增强能解释多少 CT 缺口；
- OARF CT/CP/FM 只用于最终比较。

本轮并不声称 Snel 模型就是 XV-15 的真实三维旋转气动模型。

## 3. 为什么使用 scalar-C81 作为本轮基线

前一层已经证明，把 NASA 四段径向 C81 + 局部 Mach 压成一组 scalar-C81 后，并不会解释当前约 40%--50% 的主要 CT 缺口。为了避免在本轮再引入“局部 C81 失速角如何定义”的新自由度，旋转增升量级筛查使用已经独立由 NASA C81 约化得到的 scalar-C81：

- `alpha0L ≈ -1.034 deg`
- `liftSlope ≈ 7.81 rad^-1`
- `CLmax ≈ 1.279`
- `CD0 ≈ 0.00497`
- `kCD ≈ 0.02486`

这一步的目的不是回到 generic，而是用已经验证过来源边界的低阶 C81 基线隔离三维升力增量。

## 4. 计算路径

新增：

`analysis/run_xv15_rotational_augmentation_screen.m`

它采用与 PR67 相同的 XV-15 原始金属桨低阶几何映射和 OARF Run 15 的 6°--11° 公共物理收敛区间。

前序 Eq. (12) 诊断已经发现：纯悬停中

\[
\beta_{1s}\approx-\frac{\bar v_i}{\Omega R},
\]

使方位入流谐波与 \(-\dot\beta r\) 基本抵消。因此本轮使用轴对称悬停方程做增升强度筛查，并在 \(g=0\) 时与现有 scalar-C81 BEMT 镜像逐点比较，避免把“简化筛查器自身误差”误判成三维气动效果。

## 6. 最关键结果：需要多强的旋转增升才能单独补足 CT？

把 OARF 10° CT 仅作为**事后逆向诊断目标**，求得：

\[
\boxed{g_{CT,10^\circ}\approx18.1}
\]

也就是，需要约 **18 倍名义 Snel 强度**，轴对称筛查器才能把 10° CT 从约 0.00818 拉到 0.013089。

这一数值绝不能作为新的 XV-15 参数写回模型，因为它直接利用了验证数据。它只回答一个误差归因问题：

> 如果把当前全部 CT 缺口都归因给旋转三维增升，所要求的修正量级是否合理？

答案是否定的。

在这个 18.1 倍增益下，即使 CT 被强行匹配：

- CP 仍约为 0.001215，低于试验 0.001358；
- FM 升到约 0.872，明显高于试验 0.7797。

因此“只缺一个三维增升修正”不仅需要极端强度，而且会把 CT、CP、FM 之间的误差结构推向新的不一致。

## 7. 本轮能够支持的结论

### 7.1 旋转三维效应方向正确，但只能解释一部分

名义 Snel 修正使 CT MAPE 从约 43.24% 降到 40.09%，说明当前二维截面模型遗漏旋转增升后，确实可能产生一部分系统性低估。

但改善量只有约 3 个百分点，远小于剩余误差。

### 7.2 旋转三维升力增强不是当前主误差源

即使把名义修正提高到 2 倍，CT MAPE 仍约 37%。只有把经验修正放大到十几倍乃至约 20 倍，才能大幅接近试验。

这已经超出“合理低阶三维修正”的解释范围。因此：

\[
\boxed{\text{旋转三维升力增强/失速延迟不是当前 XV-15 悬停 CT 缺口的主因。}}
\]

### 7.3 不能把高倍率结果当成新的“验模成功”

`g≈18.1` 是用 OARF CT 逆算出来的事后诊断量，不是独立参数来源。若把它写回模型再宣布验模通过，就会形成用验证数据校准验证数据的循环。

## 8. 下一层优先级

到这里，纯粹的“截面二维 -> 三维旋转增升”也已经被限制为次要因素。下一层应优先检查比局部截面修正更上游的**径向诱导速度 / 尾迹物理**：

1. 当前悬停动量闭合只使用单一平均诱导速度；
2. Eq. (12) 只提供方位一阶变化，而上一轮已经证明这部分被挥舞基本抵消；
3. 真实有限叶片旋翼的诱导速度和载荷存在明显径向耦合，局部尾迹收缩、根部/叶尖涡系和有限叶片效应会改变有效迎角分布；
4. 因此下一步更值得做的是“平均诱导速度闭合 vs 径向环量/环带动量闭合”的隔离诊断，而不是继续放大截面 CL。

叶尖损失单独加入通常会降低局部载荷，因此不能简单把它当作补足当前 CT 低估的修正；真正需要检查的是径向尾迹/诱导分布与叶素载荷的耦合方式。

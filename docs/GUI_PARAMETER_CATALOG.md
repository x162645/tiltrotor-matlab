# GUI 参数目录说明

本文件记录当前 GUI 参数目录的界面规则。完整条目由
`services/build_parameter_catalog.m` 生成，测试要求目录数量保持为 139。

## 分类原则

参数只按物理部件和计算模块分类：

| 分类 | 说明 |
|-|-|
| 环境 | 密度、重力等环境量 |
| 整机质量与惯量 | 总质量、整机惯量矩阵及倾转惯量近似系数 |
| 倾转机构 | 短舱转轴、倾转组件质量和相关几何距离 |
| 旋翼几何 | 半径、桨叶数、弦长、扭转、桨叶质量和自转惯量 |
| 旋翼运行 | 旋翼转速 |
| 旋翼气动 | 旋翼剖面气动系数和尾流系数 |
| 旋翼入流与挥舞 | 入流、挥舞和叶素离散计算设置 |
| 机翼 | 机翼几何、气动和近法向混合参数 |
| 机身 | 机身几何和气动力/力矩系数 |
| 平尾 | 平尾几何、安装角、下洗和升降舵影响 |
| 垂尾 | 垂尾几何、侧力和方向舵影响 |
| 操纵系统 | 操纵通道上下限 |
| 配平计算 | 配平残差、迭代和变量尺度 |
| 线性化计算 | 状态和操纵差分步长、模态判据容限 |

## 界面列

参数表显示：

```text
类别 | 参数 | 默认值 | 当前值 | 单位 | 状态 | 来源
```

`当前值` 可编辑。单元格编辑先进入待应用状态，点击 `应用修改`
后执行整组校验。自动派生量不作为可独立编辑项暴露；由基础参数更新的
派生量在服务层同步维护。

## 来源显示

界面把底层来源映射为自然中文，例如：

- 当前模型设定；
- 数值计算设置；
- 自动计算；
- 来源待确认。

这些显示文字不代表型号试验验证。参数来源分类和文献追溯规则仍以
`AGENTS.md` 为准。

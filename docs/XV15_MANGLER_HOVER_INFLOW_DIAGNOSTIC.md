# XV-15 悬停 Mangler–Squire 径向入流诊断

## 目的

本诊断继续 PR #68 的逐层误差归因路线。前一层已经表明：恢复 NASA 原始金属桨实际径向弦长与非线性扭转以后，简单独立环带动量相对全盘平均诱导速度只能再提供很小的额外改善。因此这里进一步检查一个**全局耦合、非线性径向入流形状**是否能够解释剩余的 XV-15 悬停推力低估。

这不是 production 模型修改，也不是 XV-15 专用自由尾迹模型。

## 采用的低阶耦合入流

Mangler–Squire 将旋翼视为升力面，通过盘面压力分布求诱导速度场。Bramwell 形式可写为：

```text
lambda_i = 4*lambda_0*(c0/2 - sum c_n cos(n psi))
```

悬停轴对称零谐波分支中：

```text
c0 = 15*mu0*(1-mu0)/8
mu0 = sqrt(1-(r/R)^2)
```

因此相对 `lambda_0` 的原始零谐波径向因子为：

```text
f_raw = (15/4)*mu0*(1-mu0)
```

其全盘面积平均为 `5/8`。若直接使用 `f_raw`，不仅改变径向形状，也同时把盘面平均入流降低 37.5%，这样无法把结果变化单独归因于“径向分布”。

因此主诊断采用**均值保持**形式：

```text
f_MS = f_raw/(5/8) = 6*mu0*(1-mu0)
vi(r) = viMean*f_MS(r)
```

从而保持：

```text
<vi(r)>_disk = viMean
```

`viMean` 仍由与当前 production Eq. (13) 等价的全盘动量闭合迭代求解。

这一定义的目的非常明确：只改变径向分布，不改变全局平均诱导速度的物理含义。

## 冻结的其他物理层

主比较保持不变：

- XV-15 原始金属桨 `R=3.81 m`、三片桨、`rootCut=0.0875`；
- NASA Appendix A 实际径向弦长分布；
- NASA Appendix A 非线性扭转多项式；
- OARF Run 15 点位转速；
- C81 独立约化得到的 scalar 低阶截面参数；
- 第一谐波挥舞；
- 当前 Eq. (12) 方位乘子；
- 全盘平均动量闭合只负责求 `viMean`；
- OARF CT/CP/FM 仅用于最后外部比较，不参与入流形状或参数拟合。

主诊断使用 `nRadial=48`，并另做 12/24/48/96 径向网格检查。

## 为什么必须做均值保持

未归一化零谐波 `f_raw` 的盘面平均仅为 `5/8`。直接使用它会在改变径向形状的同时显著降低平均入流。

方程级敏感性中，10° 点未归一化形状确实可把 CT 提高到约 `0.01048`，看起来比 GLOBAL 更接近 OARF；但这不能解释为“尾迹径向耦合改善了验模”，因为模型同时把平均入流强度改变了约 37.5%。这相当于混合了两个物理因素：

1. 径向分布形状；
2. 全盘动量水平。

因此该路径只保留为 `MANGLER_RAW_AMPLITUDE_SENSITIVITY`，不作为正式误差归因结论。

## 物理解释

均值保持 Mangler 分布在根部和叶尖降低诱导速度、在中段提高诱导速度。XV-15 原始金属桨恢复实际大负扭转后，中外段是推力的重要贡献区域；在这些区域提高诱导速度会增大入流角、降低有效迎角，从而削弱总推力。因此该经典非线性径向分布与当前所需的“补推力”方向并不一致。

这一结果与现代比较研究的一个重要事实相容：悬停中不同入流模型即使保持相同平均诱导速度，径向分布仍可明显不同；Mangler 分布通常具有强非线性，而 prescribed/free-wake 在约 0.8R 以内更接近均匀入流，主要在叶尖附近因尾迹收缩和尖涡上洗而下降。

因此本诊断不能推出“所有尾迹模型都无关紧要”，只能推出：

> **在实际径向几何、冻结 C81 截面气动和相同盘面平均动量水平下，经典 mean-matched Mangler–Squire 型径向非均匀入流不能解释当前 XV-15 悬停 CT 缺口。**

## 对误差归因链的影响

到目前为止：

1. 数值离散：不是主因；
2. generic 截面参数：有明显贡献；
3. C81 径向/Mach 标量化：不是主要剩余误差源；
4. Eq. (12) 方位一阶项：悬停中不是主因；
5. 名义旋转三维增升：小幅贡献；
6. 径向几何降阶：中等贡献；
7. 独立环带动量：在低阶几何上有一定改善，但在实际几何上额外作用很小；
8. **mean-matched Mangler 全局耦合径向入流：不改善，反而扩大 CT/CP 偏差。**

这使剩余约 28% 的高总距 CT 低估更加难以归因于“一个更好看的径向 vi(r) 形状”。下一层若继续研究尾迹，应优先考虑真正的**有限叶片 prescribed/free-wake 特征**（尖涡、尾迹收缩、径向涡诱导），而不是继续在 Mangler 形状上调幅度。

## 2. 判断一：三种配平模式是否被静默拼接

### 结论

**真实问题，严重度 HIGH。** 核心 `make_trim_definition` 和正式网格调用本来就接受显式模式，但两个公开包装器曾按 `betaM` 自动选择 `helicopter_longitudinal`、`conversion_longitudinal` 或 `airplane_longitudinal`，而且恰好 30° 时选择不一致。这种分派把三组不同未知量、约束和执行量映射伪装成一条连续定义。

旧 Berger13 包装器的实际分界是：\(\beta_M\le30^\circ\) 选直升机定义，\(30^\circ<\beta_M<60^\circ\) 选转换定义，\(\beta_M\ge60^\circ\) 选固定翼定义；参考旋翼包装器则在恰好 30° 已进入转换定义。三组定义分别为：

- 直升机：未知量 `theta/collective/cyclicLong`，固定 `elevator=0`；
- 转换：未知量 `theta/collective/pitchCommand`，由开环分配函数生成 `cyclicLong/elevator`；
- 固定翼：未知量 `theta/collective/elevator`，固定 `cyclicLong=0`。

GUI 服务 `run_trim_case` 走 legacy `trim_symmetric`，并不调用这组三模式自动选择。正式数据脚本则显式传入模式，但把不同定义放在同一结果集中：通用设计网格使用 15°/45°/75° 对应直升机/转换/固定翼，密集验证网格使用 0° 为直升机、30°/60° 为转换、90° 为固定翼。这是显式分类的离散拼接，不是隐藏控制律，也没有自动证明交界连续。

### 实测证据

在 \(V=45\ {\rm m/s}\) 对 30°、60° 两侧分别取 \(h=10^{-2},10^{-3}\) deg，并用两侧各自显式模式独立配平：

|边界|最小 \(h\)|低侧|高侧|最大直接角跳变|归一化虚拟命令跳变|判断|
|---:|---:|---|---|---:|---:|---|
|30°|0.001°|CREDIBLE|CREDIBLE|4.4957°|0.10338|未证明连续|
|60°|0.001°|FAILED|FAILED|11.6676°|约 \(2.95\times10^{-10}\)|旋翼物理闭合通过，但整机配平残差门禁未过|

完整点表和比较表分别见 `TRIM_MODE_BOUNDARY_POINTS.csv`、`TRIM_MODE_BOUNDARY_COMPARISON.csv`。端点 0°/90° 的既有等价测试只验证转换定义在端点可退化，不能替代 30°/60° 内部交接验证。

### 修复

- `trim_berger13_symmetric` 与 `trim_reference_rotor_symmetric` 现在必须显式接收 `opts.mode`，不再按短舱角隐式分派。
- 新增可重复边界审计与回归。
- 不改变三种配平定义、既有显式网格、物理参数或控制限位。
- 论文把“连续转换走廊”降级为“显式模式离散可行性网格”。

## 3. 判断二：旋翼数值收敛是否等于物理闭合

### 结论

**真实阻断性问题，严重度 CRITICAL。** Eq.13 以 `max(T,0)` 生成正推力诱导速度目标；旧 `coupledConverged` 只检查诱导速度序列变化和挥舞残差。4° 点因此可在 `vi→0` 时数值收敛，同时保留约 −930 N 推力和约 −930 N 原始动量残差，并被上层当作成功。

### 修复原则

未改变 Eq.13、叶素载荷、默认参数或负载荷。迭代结束后用未截断推力计算

\[
R_T=T_{\rm BEMT}
-2\rho A(\Omega R)v_i\sqrt{\lambda_1^2+\mu^2}.
\]
输出同时保留：

- `coupledConverged`：向后兼容的数值序列状态；
- `inducedClosureResidual`：未截断原始闭合残差；
- `physicalBranchSupported`：当前是否属于已实现的正推力分支；
- `physicalConverged` 与 `physicalStatus`：供上层接受/拒绝。

相对闭合残差门限 \(2\times10^{-4}\) 是本次新增的无量纲数值审计判据，不是飞行器参数；系数 2 对应诱导速度固定点的 0.5 松弛更新。它与有单位的 `inducedTol` 分开命名，避免把 m/s 迭代阈值误作无量纲载荷阈值。

4° 原始载荷继续返回，但状态为 `UNSUPPORTED_NEGATIVE_THRUST_BRANCH`；12° 正常分支的推力、扭矩和诱导速度基准保持到既有严格容差。

物理状态已传播至九状态与十三状态合力/运动方程、通用和对称配平、可信度诊断、Berger13 配平与 GUI 服务。为保留搜索路径，目标函数仍计算原残差，但会记录无效物理状态；最终接受门禁明确拒绝该候选，不能再生成“成功但非物理”的结果。

外部悬停关联也按同一门禁重算。当前正式旋翼的 4° 原始负推力载荷仍保存在 CSV 中，但不再计为有效相关点；当前路径由 7 个有效点、3 个失败点更正为 6 个有效点、6 个失败点（0° 至 10°），二次数字化指标更新为 MAE \(0.0643402\)、RMSE \(0.0643727\)。这改变的是有效性统计与论文表述，不是原始载荷或物理参数。

## 4. 判断三：机翼 near-normal 符号是否与配平命令冲突

### 结论

**不构成真实代码问题。** `model/wing_model.m` 的 `normalFlowRatioActual`、过渡坐标和 `branchWeight` 全部由同一局部来流速度计算；转换配平的虚拟俯仰命令在代码中名为 `pitchCommand`，经分配日程映射到实际执行量。二者没有共享变量、函数参数或覆盖关系。

论文当前只用 \(\chi\) 表示机翼法向流比；本次补充了与 `pitchCommand` 的明确区分。无需修改机翼方程或控制映射。

质疑中引用的“第4.7节”和“第5.2节”不对应当前终稿章节结构；对当前终稿及多轮中间稿的检索没有发现第二个用 \(\chi\) 表示 `pitchCommand` 的定义。因此该质疑至多对应未定位的旧稿或外部转述，不能作为生产代码冲突的证据。
